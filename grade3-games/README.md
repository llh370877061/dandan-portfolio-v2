# 三年级下册“7天复习游戏营”

> 适用对象：三年级学生
> 复习周期：7天
> 对应教材：语文-部编版、数学-北师大版、英语-上海教育出版社（深圳专用/沪教牛津版）
> 设计目标：用游戏完成1~8单元核心复习，每天约1.5~2小时

---

## 一、使用说明

### 1. 为什么是游戏
三年级孩子注意力有限，单纯刷题容易疲倦。
游戏可以把“再练一次”变成“再玩一关”，把被动记忆变成主动提取。

### 2. 怎么用
- 每天选 **语文、数学、英语各1个小游戏**
- 也可以按孩子状态灵活替换，不一定死板按天来
- 准备一点小道具更好玩：便签纸、骰子、计时器、彩色笔、小贴纸、卡纸
- 完成后在“游戏护照”上盖章或贴贴纸，形成成就系统

### 3. 难度调节
- 偏弱的孩子：减少题量、延长提示时间、降低关卡难度
- 偏强的孩子：加时间限制、增加干扰项、加入抢答环节
- 两个孩子一起玩：加入对抗赛、合作赛

# Day1 春天探险家

## 语文游戏：诗句拼图闯关

### 对应单元
第一单元：古诗三首（绝句、惠崇春江晚景、三衢道中）、燕子、荷花

### 游戏目标
巩固本单元必背古诗和关键课文内容

### 材料准备
- 卡纸或便签纸
- 彩色笔
- 计时器

### 玩法

**第一关：诗句拼图**
1. 把5句打乱的诗句写在便签纸上，一句一张
2. 孩子要在30秒内按正确顺序排列
3. 示例：把《绝句》的四句打乱，限时排好
4. 进阶：跨诗拼图——把三首诗的句子混在一起，按诗名分类

**第二关：看图猜诗**
1. 家长画一幅简单的画（比如两只黄鹂、一行白鹭）
2. 孩子要说出对应的诗句和诗名
3. 可以画燕子、荷花、春天山景等

**第三关：填空接龙**
1. 家长说上半句，孩子接下半句
2. 例：迟日江山丽→春风花草香
3. 连续答对5句通关

### 通关标准
三关中完成两关即为通关

## 数学游戏：商是几位数接力赛

### 对应单元
第一单元：除法（分桃子、分橘子、商是几位数、猴子的烦恼、节约、集邮）

### 游戏目标
熟练判断商是几位数，巩固除法计算

### 材料准备
- 骰子2个
- 白纸
- 彩色笔

### 玩法

**第一关：骰子出题**
1. 两个骰子各掷一次，组成一个两位数作为被除数
2. 再掷一次决定除数（1~6）
3. 快速判断：商是几位数？
4. 答对得1分，10题中答对7题通关

**第二关：快速计算**
1. 家长出题：84÷4、96÷3、72÷6……
2. 孩子写竖式计算
3. 3分钟内完成8题且正确6题通关

**第三关：生活除法**
1. 情境题：48块饼干平均分给4个小朋友，每人几块？
2. 72本书平均放进6个书架，每个书架放几本？
3. 答对3题通关

### 通关标准
三关中完成两关即为通关

# Day2 故事大王

## 语文游戏：寓言故事推理局

### 对应单元
第二单元：守株待兔、陶罐和铁罐、鹿角和鹿腿、池子与河流

### 游戏目标
理解寓言寓意，培养推理能力

### 材料准备
- 故事卡片（家长提前写好）
- 答题纸

### 玩法

**第一关：故事还原**
1. 家长把一个寓言故事的关键情节打乱写在4张卡片上
2. 孩子要按正确顺序排列，并说出故事名
3. 例：守株待兔的4个关键节点

**第二关：寓意侦探**
1. 家长描述一个情境，孩子判断这像哪个寓言
2. 例："有个人天天等着兔子撞树，什么都不干了"→守株待兔
3. 例："一个很坚硬的东西和一个很柔软的东西比谁更厉害"→陶罐和铁罐
4. 答对3题通关

**第三关：故事续写**
1. 选一个寓言，想象"如果结局不一样"
2. 例：如果鹿没有嫌弃自己的腿，后来会怎样？
3. 说出3个不同的续写方向即可通关

### 通关标准
三关中完成两关即为通关

## 五、家长小贴士

1. **不要贪多**：每天每个学科只玩一个小游戏就够了
