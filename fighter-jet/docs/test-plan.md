## P0 存活测试（4 项）

- [ ] HTML 文件可打开
  标准：浏览器控制台无 JavaScript 错误
  建议命令：`open ~/Her工作间/战斗机飞行模组/index.html`

- [ ] WebGL 上下文创建成功
  标准：canvas 元素存在且 WebGL 上下文非 null
  建议命令：浏览器开发者工具检查

- [ ] 游戏主循环运行
  标准：requestAnimationFrame 正常调用，帧率 > 30fps
  建议命令：浏览器 Performance 面板

- [ ] 基础文件结构完整
  标准：所有源文件存在且可读
  建议命令：`ls -la ~/Her工作间/战斗机飞行模组/src/`

---

## P1 核心功能 E2E（6 项）

- [ ] [frontend] 飞机选择界面显示所有 8 种飞机
  标准：界面显示歼-20、歼-35、歼-16、歼-10、米格-25、米格-27、运-20、轰炸机选项
  建议命令：手动验证

- [ ] [frontend] 起飞流程完整
  标准：按 W 加速，速度达到抬轮速度后可拉起，飞机离地升空
  建议命令：手动验证

- [ ] [frontend] 飞行姿态控制响应
  标准：按 WASD/方向键，飞机姿态实时响应，仪表盘同步更新
  建议命令：手动验证

- [ ] [e2e] 战斗系统完整
  标准：敌机出现→锁定→发射导弹→命中爆炸→敌机消失
  建议命令：手动验证

- [ ] [e2e] 降落流程完整
  标准：对准跑道→减速→下降→安全着陆，飞机停稳
  建议命令：手动验证

- [ ] [e2e] 胜利条件触发
  标准：摧毁敌方所有基地建筑后显示胜利画面
  建议命令：手动验证
