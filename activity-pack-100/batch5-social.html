方案 41

职业大调查

主题：职业认知时长：2-3小时

活动简介

社区里有多少种职业？保安、保洁、快递员、便利店店员、外卖员、物业管理员、花店老板……采访不同职业的人，了解他们的工作内容、工作时间、最辛苦的部分和最开心的部分。

分龄设计

年龄段任务
4-6岁认识3种职业：看看他们在干什么，画下来
7-9岁采访2种职业：问3个问题，记录回答
10-12岁做一份"社区职业图谱"：采访4-5种职业，分析社区的职业生态

多元智能

人际（核心：采访交流）、语言（提问和记录）、观察力（观察工作场景）、逻辑（分析职业关系）、内省（思考"我以后想做什么"）

具体步骤

  1. 列清单（10分钟）：在社区里能找到哪些职业？
  2. 采访（60-90分钟）：找到不同职业的人，进行采访
  3. 记录（20分钟）：整理采访记录
  4. 分享（15分钟）：互相介绍"我采访的职业"

产出

  • 4-6岁：3张"职业画像"
  • 7-9岁：一份"职业采访记"（2种职业）
  • 10-12岁：一份"社区职业图谱"（含职业分布、工作内容分析）

引导话术

"你觉得这个叔叔/阿姨每天几点上班？几点下班？"

"这个工作最辛苦的是什么？最开心的是什么？"

"如果你来做这个工作，你觉得最难的是什么？"

方案 42

社区运转的秘密

主题：社区运作时长：2小时

活动简介

社区每天都在运转——垃圾谁来收？水电怎么来的？快递怎么送到的？保安怎么知道谁是住户？了解社区的"基础设施"和"运作系统"，理解我们每天享受的服务是怎么来的。

分龄设计

年龄段任务
4-6岁找一找：找到社区里的设施（路灯、消防栓、配电箱、垃圾桶）
7-9岁画一张"社区运作图"：标注不同设施的位置和功能
10-12岁做一份"社区运作报告"：分析社区的基础设施和运作系统

多元智能

空间（观察设施位置）、逻辑（理解运作系统）、语言（描述功能）、观察力（发现设施）、人际（采访物业人员）

具体步骤

  1. 搜索（30分钟）：在社区里找到各种基础设施
  2. 采访（20分钟）：问保安或物业"这些设施是干嘛的"
  3. 记录（20分钟）：画"社区运作图"或写"社区运作报告"
  4. 讨论（10分钟）：讨论"如果没有这些设施，会怎样"

产出

  • 4-6岁：一张"我找到的设施"照片集
  • 7-9岁：一张手绘"社区运作图"
  • 10-12岁：一份"社区运作报告"（含设施分布、功能分析、改进建议）

引导话术

"你觉得我们喝的水是从哪里来的？"

"垃圾被收走之后去了哪里？"

"如果社区停电了，会发生什么？"

方案 43

规则猎人

主题：规则意识时长：1.5-2小时

活动简介

社区里有很多"规则"——交通规则、小区规定、公共场所的行为规范……找到这些规则，理解它们为什么存在，如果没有这些规则会怎样。

分龄设计

年龄段任务
4-6岁找标志：找到5个不同的标志（交通标志、警示标志）
7-9岁找规则：找到10条不同的规则，记录它们在哪里
10-12岁分析规则：找出规则，分析它们存在的原因，讨论"如果没有会怎样"

多元智能

观察力（发现规则）、逻辑（分析规则存在的原因）、语言（描述和讨论）、空间（记录规则的位置）、内省（反思自己的行为）

具体步骤

  1. 搜索（30-40分钟）：在社区里找到各种规则和标志
  2. 记录（15分钟）：拍照或画下来
  3. 讨论（20分钟）：讨论"这条规则为什么存在"
  4. 假设（10分钟）：讨论"如果没有这条规则，会怎样"

产出

  • 4-6岁：一张"我找到的标志"照片集
  • 7-9岁：一份"社区规则清单"（10条规则+位置）
  • 10-12岁：一份"规则分析报告"（含规则、原因分析、假设推演）

引导话术

"你觉得这条规则是为谁定的？"

"如果没有'禁止停车'的标志，这里会变成什么样？"

"有没有你觉得不太合理的规则？为什么？"

方案 44

社区文化地图

主题：文化感知时长：2-3小时

活动简介

社区里住着不同的人——不同的年龄、不同的职业、不同的文化背景。观察社区里的文化多样性：有什么样的商店？有什么样的节日装饰？人们说什么语言？画一张"社区文化地图"。

分龄设计

年龄段任务
4-6岁找不同：找到3种不同的商店（餐馆、花店、杂货店）
7-9岁画文化地图：标注不同商店、不同文化元素的位置
10-12岁文化调查：分析社区的文化多样性，做一份"文化地图"

多元智能

观察力（发现文化元素）、空间（画地图）、语言（描述文化差异）、人际（与不同背景的人交流）、内省（反思文化多样性）

具体步骤

  1. 搜索（40-50分钟）：在社区里寻找不同的文化元素
  2. 记录（20分钟）：拍照、画图、记录
  3. 整理（20分钟）：把记录整理成"文化地图"
  4. 讨论（10分钟）：讨论"社区里的文化多样性"

产出

  • 4-6岁：3张"不同商店"的照片
  • 7-9岁：一张手绘"社区文化地图"
  • 10-12岁：一份"社区文化调查报告"（含文化分布、多样性分析）

引导话术

"这条街上有什么不同的商店？它们卖什么？"

"你觉得住在这个社区的人来自哪些地方？"

"不同文化的人住在一起，有什么好处？有什么挑战？"

方案 45

小小公民

主题：公民意识时长：2小时

活动简介

你是社区的一份子，你有权利也有责任。了解"公民"的含义——我能为社区做什么？社区为我做了什么？做一个"社区贡献计划"。

分龄设计

年龄段任务
4-6岁找贡献：说说"我为社区做了什么"（如不乱扔垃圾）
7-9岁做计划：制定一个"本周社区贡献计划"
10-12岁写提案：写一份"社区改善提案"，提出一个具体的改进建议

多元智能

内省（反思自己的角色）、人际（与社区互动）、语言（写作和表达）、逻辑（分析社区问题）、行动力（执行贡献计划）

具体步骤

  1. 反思（10分钟）：讨论"社区为我做了什么？我为社区做了什么？"
  2. 发现（20分钟）：在社区里找到"可以改进的地方"
  3. 计划（20分钟）：制定一个"社区贡献计划"
  4. 行动（30分钟）：执行计划（如捡拾垃圾、帮助邻居）
  5. 反思（10分钟）：讨论"做了之后感觉怎么样"

产出

  • 4-6岁：一句"我为社区做了____"
  • 7-9岁：一份"社区贡献计划"+ 执行记录
  • 10-12岁：一份"社区改善提案"（含问题分析、解决方案、行动计划）

引导话术

"社区为我做了什么？我为社区做了什么？"

"你觉得你能为社区做的最重要的一件事是什么？"

"做完之后，你感觉怎么样？"

方案 46

如果我是你

主题：同理心时长：1.5-2小时

活动简介

如果我是清洁工，每天凌晨4点就要起床；如果我是保安，整夜都不能睡觉；如果我是外卖员，下雨天也要送餐……通过"角色代入"，培养同理心——理解不同人的处境和感受。

分龄设计

年龄段任务
4-6岁说感受：看到不同职业的人，说说"他们累不累"
7-9岁写日记：以"如果我是你"为主题，写一篇短文
10-12岁做访谈：采访一个你不太了解的职业，写一篇"同理心访谈"

多元智能

内省（核心：同理心）、人际（理解他人）、语言（写作和表达）、观察力（观察不同人的处境）、想象力（角色代入）

具体步骤

  1. 观察（20分钟）：观察社区里不同职业的人在做什么
  2. 代入（15分钟）：选一个人，想象"如果我是TA"
  3. 创作（30-40分钟）：写或画"如果我是你"
  4. 分享（10分钟）：互相分享"我代入的是谁"

产出

  • 4-6岁：一张"如果我是你"的画
  • 7-9岁：一篇"如果我是你"的短文
  • 10-12岁：一篇"同理心访谈"（含采访记录+反思）

引导话术

"你觉得他/她今天最辛苦的是什么时候？"

"如果让你做一天他的工作，你觉得最难的是什么？"

"你以后想对这样的人说什么？做什么？"

方案 47

社区经济学

主题：经济认知时长：2小时

活动简介

社区里处处是"经济"——商店怎么赚钱？为什么有的东西贵有的便宜？钱是怎么流动的？了解基本的经济概念：供需、价格、成本、利润。

分龄设计

年龄段任务
7-9岁价格调查：比较3种商品在不同地方的价格
10-12岁商业分析：分析一家小店的"赚钱逻辑"

多元智能

逻辑数学（核心：价格计算、成本分析）、语言（采访和描述）、人际（与店主交流）、观察力（观察商业运作）、内省（思考消费行为）

具体步骤

  1. 调查（40分钟）：在便利店、超市、小摊比较商品价格
  2. 采访（20分钟）：问店主"什么卖得最好？为什么定价是这样？"
  3. 计算（15分钟）：估算一家店每天的营业额和利润
  4. 讨论（15分钟）：讨论"钱是怎么流动的"

产出

  • 7-9岁：一张"价格对比表"
  • 10-12岁：一份"社区商业分析报告"（含价格对比、成本估算、利润分析）

引导话术

"同样的东西，为什么这里卖3块，那里卖2块？"

"你觉得这家店一天能赚多少钱？"

"如果你来开一家店，你想卖什么？你觉得能赚钱吗？"

方案 49

社区声音地图

主题：社区感知时长：1.5-2小时

活动简介

每个社区都有自己独特的"声音"——早上有鸟叫和早餐摊的声音，中午有放学的喧闹，晚上有广场舞的音乐。画一张"声音地图"，标注社区在不同时间的声音。

分龄设计

年龄段任务
4-6岁听声音：在社区里走一圈，说说"听到了什么"
7-9岁画声音地图：标注不同地点的声音
10-12岁时间维度：在不同时间段观察，画一张"社区声音时间表"

多元智能

听觉（核心）、空间（定位声音来源）、时间感知（不同时间的声音变化）、语言（描述声音）、艺术（画声音地图）

具体步骤

  1. 漫步（30-40分钟）：在社区里走，记录听到的声音
  2. 定位（15分钟）：标注声音的来源和位置
  3. 整理（20分钟）：画"声音地图"
  4. 讨论（10分钟）：讨论"社区的声音有什么特点"

产出

  • 4-6岁：一段"声音日记"（口述）
  • 7-9岁：一张"社区声音地图"
  • 10-12岁：一份"社区声音时间表"（不同时间段的声音记录）

引导话术

"早上和晚上，社区的声音有什么不一样？"

"你最喜欢社区的什么声音？最不喜欢什么声音？"

"如果社区完全没有声音，你觉得怎么样？"

方案 50

我的社区名片

主题：社区认同时长：2小时

活动简介

为你所在的社区设计一张"名片"——社区的名字、特色、最值得骄傲的地方、最需要改进的地方。这是对社区探索的一次"总结性"活动，帮助孩子建立对社区的认同感。

分龄设计

年龄段任务
4-6岁画社区：画一幅"我的社区"的画
7-9岁设计名片：设计一张社区名片（含名字、特色、一句话介绍）
10-12岁做名片+写介绍：设计名片+写一段"社区介绍"

多元智能

空间（设计名片）、语言（写介绍）、艺术（美术设计）、内省（社区认同感）、观察力（回顾探索发现）

具体步骤

  1. 回顾（10分钟）：回忆之前的探索，说说"社区最特别的地方是什么"
  2. 讨论（10分钟）：讨论"社区名片上应该写什么"
  3. 设计（30-40分钟）：设计社区名片
  4. 展示（10分钟）：互相展示设计的名片

产出

  • 4-6岁：一幅"我的社区"的画
  • 7-9岁：一张设计好的"社区名片"
  • 10-12岁：一张"社区名片"+ 一段"社区介绍"

引导话术

"如果让你用一句话介绍你的社区，你会怎么说？"

"社区最让你骄傲的是什么？最想改变的是什么？"

"你觉得别人看到这张名片，会想来你的社区吗？"
