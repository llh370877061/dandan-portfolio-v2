# 废墟突击 — FPS 射击游戏设计文档

## 概述

第一人称射击游戏，设定在废弃城市、办公楼、庄园三种场景中。玩家每局携带1把枪+1把刀，与3名AI队友配合，击退一波又一波的土匪敌人。

---

## 游戏流程

```
启动 → 主菜单 → 选择地图 → 装备武器（1枪+1刀）→ 加载 → 进入游戏
                                                    ↓
                                              第1波敌人刷新
                                                    ↓
                                           清除所有敌人 → 第2波（更强）
                                                    ↓
                                           全部5波清除 → 胜利 → 结算画面
                                                    ↓
                                           血量归零 → 失败 → 返回菜单
```

## 队友系统

每局随机分配 **3名队友**，各司其职：

### 盾牌队友

- **职责**：举大盾挡在队伍前方，吸收伤害
- **行为**：
  - 移动到玩家前方5-8米
  - 面朝敌人方向举盾
  - 盾牌HP：500（每局刷新）
  - 盾牌被击破后变为普通射击（手枪）
  - 会缓慢推进，为队伍创造前进空间
- **视觉**：手持大型防弹盾牌，蓝色轮廓

### 火箭炮队友

- **职责**：远程火力压制
- **行为**：
  - 保持在玩家后方8-12米
  - 优先攻击聚集的敌人群
  - 射击间隔：4秒（装填时间）
  - 火箭伤害：150（范围AOE）
  - 弹药有限（每局12发），会切换手枪
  - 发现重装敌人时优先开火
- **视觉**：肩扛火箭发射器，橙色轮廓

### C4队友

- **职责**：近战爆破，高风险高回报
- **行为**：
  - 快速接近敌人（移动速度最快）
  - 到达敌人5米范围内安放C4
  - C4安放时间：2秒，之后跑开3秒引爆
  - 爆炸伤害：300（范围8米）
  - 每局C4数量：8个
  - C4用完后切换冲锋枪作战
- **视觉**：背负C4炸药包，红色轮廓

## 敌人AI行为

```
闲置（出生点附近）
    ↓ 发现玩家（视野锥：前方120°，距离50米）
警戒
    ↓ 进入攻击范围
攻击（根据类型执行不同战术）
    ↓ 受伤/被压制
寻找掩体
    ↓ 掩体被摧毁/无路可退
拼命冲锋
    ↓ HP归零
死亡（消失，掉落弹药包）
```

**视野系统**：
- 视野锥：前方120°，距离50米
- 听觉范围：枪声吸引30米内敌人
- 被背刺时不会预警

**掩体系统**：
- 敌人会主动寻找掩体（墙壁、车辆、桌椅）
- 掩体有HP，被摧毁后敌人重新寻找
- 重装土匪的盾牌也是掩体

## 伤害系统

### 命中区域

| 区域 | 伤害倍率 |
|------|---------|
| 头部 | x2.5 |
| 躯干 | x1.0 |
| 四肢 | x0.75 |

### 护甲系统（玩家）

- 初始护甲：100
- 护甲吸收50%伤害
- 护甲不恢复，弹药包不恢复护甲
- 护甲归零后受到全额伤害

## 交互系统

### 弹药补给

- 敌人死亡有30%概率掉落弹药包
- 弹药包恢复当前武器30%弹容量
- 队友击杀也产生弹药包

### 击杀反馈

- 击杀显示伤害数字
- 爆头显示特殊标记
- 连杀显示连杀数（3连杀、5连杀、10连杀）
- 击杀音效随武器不同

## 技术实现

- **引擎**：Three.js（WebGL 3D渲染）
- **物理**：Cannon.js（碰撞检测）
- **风格**：低多边形（Low Poly），不需要精细模型
- **性能目标**：60FPS，支持中等配置电脑
- **兼容性**：Chrome/Edge/Firefox 最新版
