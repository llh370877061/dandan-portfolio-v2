# 第4次活动 · 精细 Prompt

> 活动名称：画一张社区地图
> 核心目标：整合前几次的发现，用地图表达对社区的理解，投票选出"最想改变的一件事"
> 参与者：6-8个孩子（9-11岁）+ 4-5个家长
> 活动时长：2-2.5小时
> 绘本：回顾《街道是大家的》中画地图的情节
> ⚠️ 这是转折点：从"观察"转向"行动"

---

## Prompt A：逐字稿

```
你是一位温暖、有感染力的儿童社区探索活动领队，现在要为第4次活动写一份逐字稿。这次的主题是"画一张社区地图"，孩子们要把前3次的发现整合成一张地图，然后投票选出最想改变的问题。这是从"观察"到"行动"的关键转折点。

【参与者信息】
- 6-8个孩子（9-11岁），已经参加过3次活动，非常熟悉
- 4-5个家长陪同，已经有丰富的参与经验
- 孩子们已经有侦察报告、人物小传、五维观察卡等素材

【活动流程及时间分配】
1. 0:00-0:15 社区记忆接龙（热身+回顾）
2. 0:15-0:30 地图绘制示范+符号介绍
3. 0:30-1:20 分组绘制社区地图（50分钟）
4. 1:20-1:50 地图展示会
5. 1:50-2:10 投票选出"最想改变的一件事"

【逐字稿要求】

请为每个环节写出完整的引导语，格式如下：

---
【环节名称】 时间段

（你站在白板前，手里拿着马克笔）

"……"（具体的开场白/引导语）

[转身在白板上写下关键词]

"……"（引导话术）

孩子可能说："……"（预判3种可能的回答）

你回应："……"（针对每种回答的具体回应）
---

具体要求：

1. **社区记忆接龙环节**：
   - 开场白："今天我们来做一件特别的事——把我们前3次探索的所有发现，画在一张地图上！"
   - 不看任何材料，一起回忆：我们去了哪里？看到了什么人？发现了什么问题？
   - 在白板上按"人·文·地·产·景"分类记录
   - 引导孩子发现："原来我们已经发现了这么多东西！"
   - 成就感时刻

2. **地图绘制示范环节**：
   - 展示几种不同风格的社区地图（手绘、漫画、标注式）
   - 介绍符号系统：
     - ⭐ = 最喜欢的地方
     - ❓ = 有疑问的地方
     - ❗ = 需要改变的地方
     - 👤 = 重要的人
   - 在纸上示范画一小段地图（快速画，展示"不需要画得精确"）
   - 强调："地图不是要画得像，重要的是表达你认为重要的东西"
   - 自然过渡到分组创作

3. **分组创作环节**：
   - 分组方法（今天怎么分）
   - 每组用一张A2大白纸，彩色笔、贴纸、照片等
   - 创作要求：
     - 至少5个地点
     - 至少3个"人"
     - 用符号标注"喜欢/疑问/需要改变"的地方
   - 参考之前的侦察报告和照片
   - 大人帮忙写字（如果孩子需要），但布局和内容由孩子决定
   - 在创作过程中怎么巡视各组（每组停留2-3分钟）
   - 如果孩子问"这样画对吗"怎么回答（"没有对错，你画的就是你的社区"）
   - 如果有孩子什么都不画怎么办
   - 50分钟的节奏把控（什么时候提醒"还有20分钟""还有10分钟"）

4. **地图展示会环节**：
   - 每组展示自己的地图，讲解3-5分钟
   - 引导语："请每组派代表来介绍你们的地图"
   - 讲解时其他组可以提问
   - 引导发现：不同组的地图有什么不同？（同一社区，不同人眼中的样子）
   - 引导发现：哪些地方被标注了"需要改变"？
   - 成就感时刻

5. **投票环节**：
   - "现在我们要做一件很重要的事——从所有'需要改变'的地方里，选出一个我们最想改变的"
   - 投票方法（举手/贴纸投票）
   - 投票前的讨论："为什么你想选这个？"
   - 统票、宣布结果
   - 引导思考："好！那我们下次就要为这个目标制定行动计划！"
   - 预告下次活动

【整体语言风格】
- 这次活动比较"静态"（画画+讨论），要保持孩子的兴奋度
- 多用"你们前3次的发现太棒了""今天要把所有发现拼成一幅完整的画"
- 投票环节要制造"民主决策"的仪式感
- 关键话术加粗
- 标注语气提示：[兴奋地] [郑重地] [竖起大拇指]

总字数控制在2500字以内。
```

## Prompt B：活动前准备清单

```
你是一位经验丰富的儿童活动策划师，现在要为第4次社区探索活动制定详细准备清单。

【活动信息】
- 活动名称：画一张社区地图
- 参与者：6-8个孩子 + 家长
- 核心材料：A2大白纸（每组1张）、彩色笔、马克笔、贴纸、之前的侦察报告和照片

【请按时间倒推列出准备清单】

一、活动前3天
- A2大白纸采购（每组1张+备用1张）
- 彩色笔/马克笔确认（够不够用）
- 贴纸采购（彩色贴纸，用于投票）
- 之前活动的素材整理（侦察报告、人物小传、照片，打印出来供参考）
- 家长群通知文案

二、活动前1天
- 材料打包清单
- 地图展示区的布置方案
- 投票环节的准备（投票贴纸、计票纸）
- 备用方案（如果孩子画不完怎么办）

三、活动当天
- 桌子摆放（每组一张桌子+大白纸）
- 材料分发
- 白板准备（用于记录讨论）
- 拍照提醒（记录创作过程）

四、家长沟通
- 给家长的说明（今天是"整合+决策"日）
- 家长的角色（帮写字、拍照、不主导内容）

【输出要求】
- 清单格式，可直接打印执行
- 素材整理要具体到"把第2次的侦察报告打印出来，每组1份"
- 文案示例可直接复制
- 总字数控制在2000字以内
```

## Prompt C：现场引导技巧手册

```
你是一位有10年经验的儿童户外教育导师，现在要为第4次"画一张社区地图"活动准备现场引导手册。

【场景设定】
- 6-8个孩子（9-11岁）+ 家长，第4次参加活动
- 今天要画社区地图，然后投票选"最想改变的事"
- 活动流程：热身回顾→示范→画地图→展示→投票

【请分场景回答，每个场景给2-3个具体方法，每个方法配一句示范话术】

一、热身回顾环节
- 孩子说"我忘了之前发现了什么"怎么办
- 回顾时孩子说的内容太多白板写不下怎么办
- 有孩子一直说、不让别人说怎么办

二、画地图环节
- 有孩子说"我不会画画"怎么办（最常见！）
- 有孩子画得和真实地图不一样怎么办（不要纠正！）
- 有孩子不知道画什么怎么办
- 有孩子想画但不知道怎么开始怎么办（给一个具体起点）
- 有孩子只想画不想写字怎么办
- 有孩子说"我的和别人画得不一样"怎么回应
- 有孩子一直画一个地方画了很久怎么办
- 小组内有分歧（想画不同的东西）怎么处理
- 时间过了30分钟有的组还没画完怎么办
- 有孩子中途说"我不想画了"怎么办

三、地图展示环节
- 有孩子不愿意上台展示怎么办
- 有孩子讲解时语无伦次怎么办
- 有孩子说"我们的地图最好看"怎么引导
- 有孩子嘲笑别的组的地图怎么办
- 展示时间不够怎么办

四、投票环节
- 有孩子想选的问题不在清单上怎么办
- 投票时有孩子跟风选别人选的怎么办
- 投票结果出来后有孩子不高兴怎么办
- 如何让投票结果有"仪式感"（让孩子觉得这是集体的决定）

五、全程通用
- 这次活动偏"静态"，如何保持孩子的参与度
- 如何让孩子感受到"前3次的观察是有意义的"
- 如何让孩子对"改变"产生期待

【输出要求】
- 不要理论，要"我现在就可以照着做"的操作指南
- 特别关注"孩子说不会画画"这个最常见的状况
- 总字数控制在2500字以内
```

## Prompt D：活动后收尾与家长沟通

```
你是一位儿童活动运营专家，现在要指导一位新手领队完成第4次活动后的收尾工作。

【背景】
- 第4次活动刚结束
- 孩子们画了社区地图，投票选出了"最想改变的一件事"
- 这是转折点——从"观察阶段"进入"行动阶段"
- 下一次（第5次）就是制定行动计划

【请完成以下四项任务】

一、5分钟收尾环节
- 总结今天的投票结果（让孩子有"我们决定了"的成就感）
- 预告下次活动："下次我们就要制定真正的行动计划了！"
- 结束仪式

二、当天晚上整理
- 社区地图拍照存档（每组一张，高清拍摄）
- 投票结果记录（哪个问题被选中、票数）
- 照片整理（创作过程、展示过程、投票过程）
- 为展览积累的素材清单
- 为第5次活动准备什么（回顾投票结果，想想怎么引导孩子制定计划）

三、微信群反馈
请写出3条不同风格的反馈模板：

模板A（简洁版）：
- 核心：今天画了地图+投票选出了改变方向+下次预告

模板B（温馨版）：
- 核心：地图创作回顾+孩子们的创意+投票结果+下次预告

模板C（详细版）：
- 核心：活动回顾+各组地图亮点+投票过程+选出的问题+孩子在决策中的表现+下次预告

重点传递：孩子们已经开始"做决定"了，这是成长的重要一步。

四、家长信任巩固
- 第4次活动后家长应该已经非常信任你了
- 如何让家长为第5-6次活动做更积极的准备
- 如何让家长开始跟朋友说"我们孩子的活动要办展览了"
- 如何为第6次展览提前造势

【输出要求】
- 微信群模板可直接复制使用
- 总字数控制在2500字以内
```

## 使用说明

1. 活动前3天：用 **Prompt B**（准备清单）采购材料、整理前3次的素材
2. 活动前1天：用 **Prompt A**（逐字稿）过一遍流程
3. 活动当天：带着 **Prompt C**（引导技巧手册）去现场
4. 活动当晚：用 **Prompt D**（收尾与家长沟通）做整理和反馈
