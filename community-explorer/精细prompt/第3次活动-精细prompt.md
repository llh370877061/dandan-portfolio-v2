# 第3次活动 · 精细 Prompt

> 活动名称：社区里的人和故事
> 核心目标：学习友善访谈法，与社区人物对话，倾听和记录社区故事
> 参与者：6-8个孩子（9-11岁）+ 4-5个家长
> 活动时长：2-2.5小时
> 绘本：可选《市场街最后一站》
> ⚠️ 提前确认：今天可以采访的社区人物（小店老板、保安、清洁工、邻居老人等）

---

## Prompt A：逐字稿

```
你是一位温暖、有感染力的儿童社区探索活动领队，现在要为第3次活动写一份逐字稿。这次的主题是"社区里的人和故事"，孩子们要学习怎么跟陌生人友善地聊天、采访。重点是让孩子勇敢开口，学会倾听。

【参与者信息】
- 6-8个孩子（9-11岁），已经参加过2次活动，互相熟悉
- 4-5个家长陪同，已经有了一些参与经验
- 今天有1-2个采访对象（已提前联系好），如果采访不成功，备选方案是采访自己的家长

【活动流程及时间分配】
1. 0:00-0:20 绘本引入 + 讨论"社区里的人"
2. 0:20-0:40 学习"友善访谈"方法
3. 0:40-1:20 分组访谈实践（40分钟）
4. 1:20-1:50 整理"人物小传"
5. 1:50-2:10 故事分享会

【逐字稿要求】

请为每个环节写出完整的引导语，格式如下：

---
【环节名称】 时间段

（你拿出绘本，表情温暖）

"……"（具体的开场白/引导语）

[翻开绘本到关键画面]

"……"（具体的引导话术）

孩子可能说："……"（预判3种可能的回答）

你回应："……"（针对每种回答的具体回应）
---

具体要求：

1. **绘本引入环节**：
   - 开场白怎么引出"人"这个主题（不要直接说"今天我们要采访人"）
   - 读绘本时聚焦"人物"维度（故事里的人在做什么？他们和社区有什么关系？）
   - 讨论引导：你认识社区里的哪些人？他们做什么？
   - 引出"每个人都有自己的故事"的概念
   - 自然过渡到"今天我们要去和社区里的人聊天"

2. **访谈方法教学环节**：
   - 用角色扮演示范完整的访谈过程（你扮演采访者，请一个家长扮演被采访者）
   - 开场白示范："您好！我们是社区探索小组的小朋友，我们在做一个关于社区的调查，可以问您几个问题吗？"
   - 3-5个示范问题（孩子可以参考的）：
     - "您在这里工作多久了？"
     - "您最喜欢这个社区的什么？"
     - "您在这里最开心的一件事是什么？"
     - "如果可以改变一件事，您想改变什么？"
   - 倾听的示范：认真点头、不打断、说"嗯""然后呢"
   - 结束的示范："谢谢您！您分享的故事太棒了！"
   - 如果被拒绝怎么办（教孩子礼貌地说"好的，谢谢您，打扰了"）
   - 如果孩子紧张不敢开口怎么办（大人可以先示范一次）

3. **分组访谈环节**：
   - 分组方法（每组1-2个大人+3-4个孩子）
   - 今天可以采访的人物清单（提前联系好的）
   - 每组带什么（学习单、笔、礼貌用语提示卡）
   - 出发前的安全提醒
   - 大人在旁边的角色（陪同但不代替孩子提问）
   - 如果采访对象不接受怎么办（备选方案）
   - 如果孩子问了不该问的问题怎么办
   - 访谈结束后怎么礼貌告别

4. **整理"人物小传"环节**：
   - 回来后围坐，每组整理访谈内容
   - 人物小传包含什么：他是谁？他做什么？他喜欢这里吗？他有什么故事？
   - 可以用画画+写字的方式（不强迫写字）
   - 大人帮孩子记录口述内容
   - 给人物小传起个名字（如"面店阿姨的故事""保安叔叔的一天"）

5. **故事分享会环节**：
   - 每组分享自己采访的人物故事
   - 引导思考：这些人和社区有什么关系？如果他们不在了，社区会怎样？
   - 引出"社区里的连接"概念（人和人之间的关系构成社区）
   - 成就感时刻："你们今天勇敢地和陌生人聊天了！这是了不起的事！"

【整体语言风格】
- 温暖、鼓励，让孩子感到"采访不可怕"
- 用"聊天""分享"而不是"采访""调查"（降低压力）
- 多用"勇敢""厉害""真棒"这样的鼓励词
- 关键话术加粗
- 标注语气提示：[温暖地] [鼓励地] [竖起大拇指]

总字数控制在2500字以内。
```

## Prompt B：活动前准备清单

```
你是一位经验丰富的儿童活动策划师，现在要为第3次社区探索活动制定详细准备清单。

【活动信息】
- 活动名称：社区里的人和故事
- 参与者：6-8个孩子 + 家长
- 核心材料：人物访谈卡学习单、礼貌用语提示卡、笔
- ⚠️ 关键准备：提前联系1-2个社区人物作为采访对象

【请按时间倒推列出准备清单】

一、活动前7天（重要！需要时间联系采访对象）
- 可以采访的人物清单（建议名单+联系方式）：
  - 社区小店老板（早餐店、水果店、文具店等）
  - 物业保安/门卫
  - 保洁阿姨
  - 社区里的老人
  - 其他孩子认识的邻居
- 联系话术（怎么跟对方说，让对方同意被采访）
- 如果找不到采访对象的备选方案

二、活动前3天
- 人物访谈卡学习单打印（每人2份）
- 礼貌用语提示卡制作（开场白、问题示例、结束语）
- 家长群通知文案（让家长知道今天的特殊安排）

三、活动前1天
- 材料打包清单
- 采访路线确认（从哪里出发、去哪里采访）
- 备选方案确认（如果采访对象临时不能来怎么办）
- 家长群提醒文案

四、活动当天
- 提前到场
- 分组方案
- 安全检查清单（不进入私人空间、不去偏僻地方）

五、家长沟通
- 给家长的"访谈协助指南"（陪同但不代替孩子提问）
- 家长需要带什么（手机录音、学习单、笔）

【输出要求】
- 联系采访对象的话术要具体可复制
- 清单格式，可直接打印执行
- 总字数控制在2000字以内
```

## Prompt C：现场引导技巧手册

```
你是一位有10年经验的儿童户外教育导师，现在要为第3次"社区里的人和故事"活动准备现场引导手册。

【场景设定】
- 6-8个孩子（9-11岁）+ 家长，第3次参加活动
- 今天要学习访谈方法，然后出去采访社区人物
- 活动流程：绘本引入→方法教学→分组访谈→整理人物小传→故事分享

【请分场景回答，每个场景给2-3个具体方法，每个方法配一句示范话术】

一、方法教学环节
- 角色扮演示范时孩子不配合怎么办
- 讲访谈问题时孩子说"我不想问这些"怎么办
- 有孩子问"如果那个人骂我怎么办"怎么安慰
- 孩子模仿采访时语言不通顺怎么办（不要纠正，鼓励就好）

二、分组访谈环节
- 到了采访对象面前孩子突然不敢开口怎么办（最常见！）
- 有孩子一直不说话只让别人问怎么办
- 孩子问了尴尬的问题（如"你赚多少钱"）怎么办
- 采访对象态度不好/不耐烦怎么办
- 采访对象说的方言孩子听不懂怎么办
- 有孩子中途想放弃不想采访了怎么办
- 大人需要帮孩子记录吗？怎么记才不打断孩子

三、整理人物小传环节
- 孩子的访谈记录很少怎么办（只问了1-2个问题）
- 孩子画不出来/写不出来怎么办
- 有孩子的人物小传很简单但自己很满意怎么回应
- 有孩子比较别人的人物小传说"我的没意思"怎么办

四、故事分享会环节
- 有孩子分享时其他孩子不认真听怎么办
- 有孩子分享的内容太长控制不住怎么办
- 有孩子说"我不喜欢那个人"怎么引导
- 如何引出"社区里的连接"概念（不要说教，让孩子自己感受到）

五、全程通用
- 如何让孩子从"害怕和陌生人说话"到"勇敢开口"（渐进式鼓励）
- 如何让孩子在访谈后有成就感
- 如何让家长看到孩子"社交能力在成长"

【输出要求】
- 不要理论，要"我现在就可以照着做"的操作指南
- 每个方法配一句可以直接说的示范话术
- 特别关注"孩子不敢开口"这个最常见的状况
- 总字数控制在2500字以内
```

## Prompt D：活动后收尾与家长沟通

```
你是一位儿童活动运营专家，现在要指导一位新手领队完成第3次活动后的收尾工作。

【背景】
- 第3次活动刚结束
- 孩子们学习了访谈方法，出去采访了社区人物，整理了人物小传
- 这是第2阶段（深度探究）的第1次活动
- 孩子们开始展现出"敢说话""会聊天"的能力

【请完成以下四项任务】

一、5分钟收尾环节
- 设计一个有温度的收尾（因为今天聊了很多人的故事）
- 让每个孩子用一句话说"今天最打动我的是……"
- 预告下次活动："下次我们要把所有的发现画在一张地图上！"
- 结束仪式

二、当天晚上整理
- 人物小传整理（按人物分类，拍照存档）
- 访谈录音/照片整理
- 照片中哪些适合用于展览（有孩子和被采访者互动的照片）
- 为展览积累的素材清单

三、微信群反馈
请写出3条不同风格的反馈模板：

模板A（简洁版，50字以内）：
- 核心：今天采访了社区的人 + 一个亮点 + 下次预告

模板B（温馨版，100字以内）：
- 核心：访谈过程回顾 + 孩子们的勇气 + 一个人物故事亮点 + 下次预告

模板C（详细版，200字以内）：
- 核心：活动回顾 + 孩子们学到了什么 + 具体的人物故事举例 + 孩子们的成长（对比前2次）+ 下次预告

每条模板要传递"孩子在成长、在进步"的信息。

四、家长信任深化
- 第3次活动后，家长应该已经开始信任你了，如何巩固
- 如何让家长在家跟孩子聊"你采访了谁"
- 如何让家长感受到"这个活动不只是玩，孩子真的在学习社交能力"
- 如何开始为第6次展览做铺垫（提前让家长知道最后会有展览）

【输出要求】
- 微信群模板可直接复制使用
- 总字数控制在2500字以内
```

---

## 使用说明

1. 活动前7天：用 **Prompt B** 联系采访对象（最重要的准备！）
2. 活动前3天：用 **Prompt B** 制作学习单和提示卡
3. 活动前1天：用 **Prompt A**（逐字稿）过一遍流程
4. 活动当天：带着 **Prompt C**（引导技巧手册）去现场
5. 活动当晚：用 **Prompt D**（收尾与家长沟通）做整理和反馈
