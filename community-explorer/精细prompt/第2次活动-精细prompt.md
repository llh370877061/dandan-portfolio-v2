# 第2次活动 · 精细 Prompt

> 活动名称：小小侦察兵
> 核心目标：学习三种侦察方法（望远镜观察法、宝藏地图法、表情图法），发现社区中值得探究的问题
> 参与者：6-8个孩子（9-11岁）+ 4-5个家长
> 活动时长：2-2.5小时
> 绘本：可选，回顾《街道是大家的》中"调查"社区的做法

---

## Prompt A：逐字稿

```
你是一位温暖、有感染力的儿童社区探索活动领队，现在要为第2次活动写一份逐字稿。这次的主题是"小小侦察兵"，孩子们要像侦探一样用三种方法观察社区。重点是让孩子学会"怎么有目的地看"，而不只是"随便看看"。

【参与者信息】
- 6-8个孩子（9-11岁），第1次已经见过面，有初步认识
- 4-5个家长陪同，第1次参与后有了一些经验
- 今天会给每个孩子发"侦察兵证"，增加仪式感

【活动流程及时间分配】
1. 0:00-0:15 上次探索回顾 + 发"侦察兵证"
2. 0:15-0:35 学习三种侦察方法（望远镜观察法、宝藏地图法、表情图法）
3. 0:35-1:25 分组侦察任务（50分钟）
4. 1:25-1:55 侦察汇报会 + 问题墙
5. 1:55-2:10 体验圈反思

【逐字稿要求】

请为每个环节写出完整的引导语，格式如下：

---
【环节名称】 时间段

（你拿着一叠侦察兵证，神秘地笑着）

"……"（具体的开场白/引导语）

[拿出侦察兵证，一张一张发给每个孩子]

"……"（发证时对每个孩子说的话，要有个性化）

孩子可能说："……"（预判3种可能的回答）

你回应："……"（针对每种回答的具体回应）
---

具体要求：

1. **回顾环节**：
   - 开场白要衔接上次活动（"上次我们发现了……今天我们要做一件更酷的事"）
   - 请2-3个孩子分享"上次回去以后有没有又注意到什么"
   - 发侦察兵证的仪式感（怎么宣布、怎么发、发的时候说什么）
   - 每个孩子拿到证后怎么引导他们看看自己的"代号"
   - 介绍今天要完成的侦察任务（用孩子能理解的语言）

2. **方法教学环节**：
   - 望远镜观察法：完整的讲解+示范
     - "找一个你觉得有意思的地方，安静地看3分钟"
     - "看的时候注意：有什么人？在做什么？什么颜色？什么声音？"
     - 示范：你自己先做一次3分钟观察，然后分享"我刚才看到了什么"
     - 给孩子一个具体的观察对象（如一棵树、一个路口、一个店铺门口）
   - 宝藏地图法：完整的讲解+示范
     - "画一段你走过的路，标出你觉得重要的地方"
     - "用不同颜色标注：红色=最重要的，蓝色=有趣的，绿色=好看的"
     - 示范：在纸上快速画一小段地图
   - 表情图法：完整的讲解+示范
     - "在学习单上用表情标注社区里让你开心/无聊/难过/好奇的地方"
     - "😊=开心，😐=无聊，😟=难过，🤔=好奇"
     - 示范：你自己先标注一个地方

3. **分组侦察环节**：
   - 分组方法（今天怎么分，和上次不一样更好）
   - 出发前的安全提醒（简短版）
   - 侦察路线建议（选3-4个固定侦察点，让不同组轮流去）
   - 每组需要完成的任务清单（望远镜观察1次+画一段地图+标注表情图）
   - 大人怎么计时（3分钟观察的提醒方式）
   - 在路上怎么引导（"你们组的侦察点在哪里？准备好了吗？"）
   - 如果孩子不想画怎么办（可以说，大人帮忙记）

4. **侦察汇报会环节**：
   - 怎么让各组围坐下来
   - 每组汇报的引导语（"请侦察兵们汇报你们的发现！"）
   - 每组2-3分钟汇报，怎么控制时间
   - 重点引导发现"问题"：怎么问出"你觉得社区里有什么可以变得更好的地方？"
   - 把问题记录在"问题墙"大纸上（分类记录的方法）
   - 问题墙上的问题怎么读给大家听
   - 成就感时刻："你们今天发现了这么多问题！这些问题就是我们下次行动的方向！"

5. **体验圈反思环节**：
   - 三个层次的反思怎么引导：
     - 体验："今天最有趣/最难的是什么？"
     - 归纳："你发现了什么规律？"
     - 应用："如果下次再去，你会怎么做？"
   - 每个层次给2-3个引导问题
   - 如何让反思不变成"说教"（让孩子说，你只追问）

【整体语言风格】
- 用"侦察兵"的游戏化语言贯穿全程
- 像在执行一个秘密任务一样制造紧张感和兴奋感
- 多用"侦察""秘密""发现"这样的词
- 不要说教，让孩子在玩中学习
- 关键话术加粗
- 标注语气提示：[神秘地] [压低声音] [兴奋地]

总字数控制在2500字以内。
```

## Prompt B：活动前准备清单

```
你是一位经验丰富的儿童活动策划师，现在要为第2次社区探索活动制定详细准备清单。

【活动信息】
- 活动名称：小小侦察兵
- 参与者：6-8个孩子（9-11岁）+ 4-5个家长
- 活动地点：社区周边（与第1次相同的区域，但可以探索不同路线）
- 核心材料：侦察兵证（提前制作）、侦察报告学习单、彩色笔、计时器

【请按时间倒推列出准备清单】

一、活动前3天
- 侦察兵证制作清单（10款不同样式，打印在彩色卡纸上，裁剪好）
  - 具体尺寸、打印纸张、裁剪方式
- 侦察报告学习单打印（每人2份，备用）
- 问题墙大纸准备（A2白纸+马克笔）
- 家长群通知文案（示例，制造"侦察任务"的期待感）
- 天气确认

二、活动前1天
- 材料打包清单（逐项打勾）
- 侦察路线确认（选3-4个侦察点，确认安全）
- 如果下雨怎么办
- 家长群提醒文案

三、活动当天
- 提前到场布置
- 侦察兵证摆放方式（每人一张，放在座位上）
- 分组方案（提前想好）
- 安全检查清单

四、家长沟通
- 给家长的"侦察任务说明"（让家长知道今天要做什么）
- 家长在侦察环节的角色（帮计时、拍照、不干涉观察内容）

【输出要求】
- 清单格式，可直接打印执行
- 侦察兵证制作要具体到"用什么纸、怎么打印、怎么裁剪"
- 文案示例可直接复制
- 总字数控制在2000字以内
```

## Prompt C：现场引导技巧手册

```
你是一位有10年经验的儿童户外教育导师，现在要为第2次"小小侦察兵"活动准备现场引导手册。

【场景设定】
- 6-8个孩子（9-11岁）+ 家长，第2次参加活动
- 今天发侦察兵证，学习三种侦察方法，然后出去"侦察"
- 活动流程：回顾→方法教学→分组侦察→汇报→反思

【请分场景回答，每个场景给2-3个具体方法，每个方法配一句示范话术】

一、发证环节
- 发侦察兵证时如何制造仪式感
- 如果有孩子说"我不想叫这个代号"怎么办
- 如果有孩子说"为什么他的比我好看"怎么办

二、方法教学环节
- 讲望远镜观察法时孩子注意力不集中怎么办
- 讲宝藏地图法时孩子说"我不会画"怎么办
- 讲表情图法时孩子不理解为什么要用表情怎么办
- 示范3分钟观察时孩子坐不住怎么办

三、分组侦察环节
- 侦察过程中孩子走散了怎么办
- 有孩子不观察只顾着玩怎么办
- 有孩子一直问你"这样对吗"怎么办
- 有孩子不愿意画只想用手机拍怎么办
- 经过不认识的人时孩子太热情去搭话怎么办
- 天太热/太冷孩子不想继续怎么办

四、汇报环节
- 有孩子说"我们组什么都没发现"怎么办
- 有孩子说的发现和主题无关怎么办
- 有孩子在别人汇报时说话不认真听怎么办
- 问题墙上的问题太少怎么办
- 有孩子提的问题太抽象（如"为什么世界是这样的"）怎么引导具体化

五、反思环节
- 孩子说"今天没什么难的"怎么引导深入反思
- 孩子的反思只停留在"好玩"层面怎么引导

六、全程通用
- 如何让第2次活动比第1次更有"进步感"（让孩子觉得自己在成长）
- 如何让家长看到孩子的变化

【输出要求】
- 不要理论，要"我现在就可以照着做"的操作指南
- 每个方法配一句可以直接说的示范话术
- 总字数控制在2500字以内
```

## Prompt D：活动后收尾与家长沟通

```
你是一位儿童活动运营专家，现在要指导一位新手领队完成第2次活动后的收尾工作。

【背景】
- 第2次活动刚结束
- 孩子们学了三种侦察方法，做了实地侦察，建了"问题墙"
- 孩子们已经有一定默契，开始有"小团队"的感觉
- 拍了照片，有侦察报告和问题墙

【请完成以下四项任务】

一、5分钟收尾环节
- 设计一个仪式感收尾，让孩子觉得"今天我是真正的侦察兵"
- 回顾今天学到了什么（让孩子自己说，不要你总结）
- 预告下次活动（"下次我们要去采访社区里的人！"制造期待）
- 结束口令/动作

二、当天晚上整理
- 侦察报告整理方法（按孩子分类，扫描或拍照存档）
- 问题墙拍照+文字记录（按类型分类：环境问题、设施问题、人际关系问题等）
- 照片整理（哪些是"侦察过程"照片，哪些是"作品"照片）
- 为展览积累的素材清单（从第2次开始要记录什么）

三、微信群反馈
请写出3条不同风格的反馈模板：

模板A（简洁版，50字以内）：
- 核心：今天是侦察兵 + 一个亮点 + 下次预告

模板B（温馨版，100字以内）：
- 核心：侦察过程回顾 + 孩子们的成长（和第1次对比）+ 下次预告

模板C（详细版，200字以内）：
- 核心：活动回顾 + 三种侦察方法介绍 + 孩子们的具体发现（举例）+ 问题墙上的问题 + 下次预告

每条模板要体现"孩子在成长"的信息。

四、家长信任巩固
- 第2次活动后，家长可能有的新顾虑
- 如何让家长看到"孩子真的在学习"（而不只是玩）
- 如何让家长开始主动跟朋友推荐这个活动
- 如何引导家长在家里延续活动（"回家可以试试望远镜观察法"）

【输出要求】
- 微信群模板可直接复制使用
- 整理清单具体到文件操作步骤
- 总字数控制在2500字以内
```

## 使用说明

1. 活动前3天：用 **Prompt B**（准备清单）制作侦察兵证、打印学习单
2. 活动前1天：用 **Prompt A**（逐字稿）过一遍流程
3. 活动当天：带着 **Prompt C**（引导技巧手册）去现场
4. 活动当晚：用 **Prompt D**（收尾与家长沟通）做整理和反馈
