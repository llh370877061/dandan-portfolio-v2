# 第1次活动 · 精细 Prompt

> 活动名称：出发！走进我们的社区
> 核心目标：认识社区探索活动的意义，用五官初步感受社区，了解"人·文·地·产·景"五维观察法，建立团队归属感
> 参与者：6-8个孩子（9-11岁）+ 4-5个家长
> 活动时长：2-2.5小时
> 绘本：《街道是大家的》（必选）

---

## Prompt A：逐字稿

```
你是一位温暖、有感染力的儿童社区探索活动领队，现在要为第1次活动写一份逐字稿。这是孩子们第一次参加社区探索，最重要的是激发好奇心和建立信任。

【参与者信息】
- 6-8个孩子（9-11岁），有些互相认识，有些不认识
- 4-5个家长陪同，有些很积极，有些还在观望
- 可能有1-2个孩子比较内向，不太敢说话
- 其中一个家庭有两个孩子（8岁和5岁），可能注意力较短

【活动流程及时间分配】
1. 0:00-0:20 破冰游戏"社区接龙"
2. 0:20-0:50 共读《街道是大家的》
3. 0:50-1:10 介绍"五维观察法"（人·文·地·产·景）
4. 1:10-1:50 初次社区漫步（分2-3组）
5. 1:50-2:10 围坐分享"我发现了……"
6. 2:10-2:20 收尾预告

【逐字稿要求】

请为每个环节写出完整的引导语，格式如下：

---
【环节名称】 时间段

（你站在大家面前，面带微笑，声音热情）

"……"（具体的开场白/引导语）

[走到某个孩子身边，蹲下来]

"……"（具体的互动话术）

孩子可能说："……"（预判3种可能的回答）

你回应："……"（针对每种回答的具体回应）

[成就感时刻]（在这个环节，什么话能让孩子觉得自己很棒）
---

具体要求：

1. **破冰环节**：
   - 开场白要让所有孩子放松，可以用"今天我们来玩一个游戏"开头
   - 社区接龙游戏的完整规则讲解（孩子能听懂的版本）
   - 示范一次怎么做（你说一个地名，然后请一个孩子接着说）
   - 如果有孩子说不出来，怎么帮他（不是替他说，而是提示"你家附近有什么？"）
   - 游戏结束时怎么庆祝大家的成绩（"我们一共发现了XX个地方！太厉害了！"）
   - 怎么自然过渡到绘本共读

2. **绘本共读环节**：
   - 开场白怎么引出绘本（不要直接说"我们来读书"，要制造期待）
   - 读到关键画面时的停顿提问（"你们猜接下来会怎样？"）
   - 读完后的3个讨论问题及追问话术：
     - "故事里的孩子们做了什么？"→ 追问："他们为什么要这样做？"
     - "他们遇到了什么困难？"→ 追问："如果是你，你会怎么办？"
     - "如果你住在那里，你想做什么？"→ 追问："为什么想做这个？"
   - 如果孩子回答"我不知道"怎么引导
   - 如果孩子回答得很简短（如"好玩"）怎么追问深入
   - 如何自然过渡到五维观察法

3. **五维观察法介绍环节**：
   - 用孩子能理解的语言解释每个维度（不是念定义，而是举例）
   - 人——"你们刚才在故事里看到的那些人，就是'人'这个维度"
   - 文——"这个社区有什么特别的传统或历史吗？"
   - 地——"我们脚下的这片土地，长什么样？"
   - 产——"社区里有什么人在做生意？"
   - 景——"走在社区里，什么景色最好看？"
   - 发给每个孩子一张五维观察卡，让他们抽一个维度
   - 抽到卡后怎么引导："好！今天你就是'XX观察员'，你的任务是……"
   - 没抽到卡的家长怎么办（家长可以做"全能观察员"）

4. **社区漫步环节**：
   - 分组的具体方法（怎么分组、每组怎么分配大人）
   - 出发前的安全提醒（孩子能记住的版本）
   - 探索路线的建议（不超过1公里，沿途有安全的停留点）
   - 在路上怎么引导孩子观察（"你抽到的是'人'，你看到什么人了吗？"）
   - 如果孩子走太快或走太慢怎么办
   - 如果孩子在一个地方停留太久怎么办
   - 大人应该走在什么位置（两侧，不要走在前面带路）
   - 大人可以说什么、不可以说什么（给大人一个简单的口头提醒）

5. **围坐分享环节**：
   - 怎么让大家安静下来围坐（一个信号或口令）
   - 每组分享的引导语（"每组用2分钟说说你们发现了什么"）
   - 每个孩子都要有机会说，怎么引导内向的孩子开口
   - 用大白纸按"人·文·地·产·景"分类记录（实时记录的话术）
   - 引导发现："同一个地方，不同人看到的东西不一样！"
   - 成就感时刻："今天我们一共发现了XX个'人'、XX个'景'……你们的眼睛太厉害了！"

6. **收尾环节**：
   - 发放学习单的引导语
   - 预告下次活动的神秘感（"下次我们要做一件更酷的事情……"）
   - 结束仪式（可以是一起喊口号或击掌）

【整体语言风格】
- 像跟朋友聊天一样自然，不要书面语
- 多用"哇""太棒了""真的吗"这样的感叹词
- 多用提问，少用陈述
- 不要说教，不说"你们要学到了什么"
- 关键话术加粗
- 标注语气提示：[兴奋地] [蹲下来] [指着某处] [停顿3秒]

总字数控制在2500字以内。
```

## Prompt B：活动前准备清单

```
你是一位经验丰富的儿童活动策划师，现在要为第1次社区探索活动制定详细准备清单。

【活动信息】
- 活动名称：出发！走进我们的社区
- 参与者：6-8个孩子（9-11岁）+ 4-5个家长
- 活动地点：社区周边街道和公园
- 核心材料：五维观察卡、学习单、A2大白纸、彩色笔、马克笔、木夹、麻绳

【请按时间倒推列出准备清单】

一、活动前3天
- 需要购买/打印的材料清单（具体数量）
- 需要制作的材料（五维观察卡怎么做、学习单打印几份）
- 家长群通知文案（示例，可以直接复制）
- 天气确认事项

二、活动前1天
- 材料打包清单（装进一个袋子里，逐项打勾）
- 场地踩点事项（路线确认、安全检查点）
- 家长群提醒文案（示例）
- 如果下雨怎么办（备选方案）

三、活动当天
- 提前多久到、布置什么
- 材料摆放位置
- 分组方案（提前想好怎么分组）
- 安全检查清单
- 开场前2分钟你要做什么（调整心态、观察孩子们的状态）

四、家长沟通
- 活动前给家长的一段话（说明活动价值，让家长放心）
- 家长在现场的角色（简短版，3句话说清楚）
- 家长需要带什么（手机拍照、饮用水等）

【输出要求】
- 用清单格式，可以直接打印出来执行
- 每项标注⏱️预估时间
- 材料清单要具体到数量
- 文案示例可以直接复制使用
- 总字数控制在2000字以内
```

## Prompt C：现场引导技巧手册

```
你是一位有10年经验的儿童户外教育导师，现在要为第1次社区探索活动准备一份现场引导手册。领队是新手，需要你手把手教她遇到各种情况怎么办。

【场景设定】
- 6-8个孩子（9-11岁）+ 家长，在社区户外活动
- 这是第1次活动，孩子和家长都是新手
- 活动流程：破冰→绘本→五维观察法→社区漫步→分享→收尾

【请分场景回答，每个场景给2-3个具体方法，每个方法配一句示范话术】

一、破冰环节可能遇到的状况
- 有孩子一直不说话怎么办（给出具体引导话术）
- 有孩子抢着说不让别人说怎么办
- 有孩子说的地名别人已经说过了怎么办
- 家长在旁边替孩子说怎么办

二、绘本共读环节可能遇到的状况
- 孩子坐不住、东张西望怎么办
- 孩子打断你不停问问题怎么办
- 讨论时所有孩子都说"不知道"怎么办
- 有孩子说"这个故事好无聊"怎么办

三、五维观察法介绍环节
- 孩子听不懂"维度"这个词怎么办
- 抽签时有孩子不喜欢自己抽到的维度怎么办
- 有孩子问"为什么我要观察这个"怎么回答

四、社区漫步环节可能遇到的状况
- 孩子走太快冲在前面怎么办
- 孩子走太慢一直拖后腿怎么办
- 孩子在一个地方停留太久（超过5分钟）怎么办
- 有孩子不想走想留在原地怎么办
- 经过商店/小摊孩子想买东西怎么办
- 路上遇到陌生人靠近怎么办（安全应对）
- 有孩子说"好累走不动了"怎么办

五、分享环节可能遇到的状况
- 回来后没人愿意第一个分享怎么办
- 有孩子的分享偏离主题怎么办
- 有孩子嘲笑别人的发现怎么办
- 时间到了但还有孩子没分享怎么办

六、全程通用
- 如何判断活动节奏是否正常（时间把控）
- 什么时候该推进、什么时候该等待
- 如何让安静的孩子有参与感（至少3种方法）
- 如何让家长也投入而不只是旁观

【输出要求】
- 不要理论，要"我现在就可以照着做"的操作指南
- 每个方法配一句可以直接说的示范话术
- 总字数控制在2500字以内
```

## Prompt D：活动后收尾与家长沟通

```
你是一位儿童活动运营专家，现在要指导一位新手领队完成第1次活动后的收尾工作。这是第1次活动，家长还在观望期，需要通过这次反馈让他们对后续活动产生信心。

【背景】
- 第1次活动刚结束
- 孩子们做了社区漫步、画了学习单、做了五维观察
- 拍了一些照片
- 家长在现场参与了

【请完成以下四项任务】

一、5分钟收尾环节（活动结束前）
- 设计一个有仪式感的收尾，让孩子觉得"今天太棒了"
- 3种收尾方式（选一种用）+ 每种的具体话术
- 如何预告下次活动（制造期待感，不要剧透太多）
- 结束口令/动作（如一起喊"探索！发现！"或击掌）

二、当天晚上整理（活动结束后2小时内）
- 哪些东西必须当天整理（照片分类、学习单归档、记录关键发现）
- 文件夹命名规则（统一格式，方便以后展览使用）
- 哪些照片要标记"展览素材"（哪些孩子/哪些作品有展览价值）
- 为下次活动准备什么（回顾今天的记录，想想下次可以怎么衔接）

三、微信群反馈（当天晚上发给家长）
请写出3条不同风格的反馈模板：

模板A（简洁版，50字以内）：
- 核心：今天很开心 + 一个亮点 + 下次预告

模板B（温馨版，100字以内）：
- 核心：今天的流程回顾 + 每个孩子的闪光点（泛指，不点名）+ 下次预告

模板C（详细版，200字以内）：
- 核心：活动回顾 + 孩子们的具体表现（举例）+ 学到什么 + 下次预告 + 感谢家长

每条模板写得自然、真诚，像朋友分享而不是官方通报。标注：[可根据实际情况修改括号内的内容]。

四、家长信任建立策略
- 第1次活动后，家长最可能有的3个顾虑是什么
- 针对每个顾虑，怎么在反馈中自然化解
- 如何让家长觉得"这个活动比我想象的好"
- 如何让家长主动告诉别的家长"这个活动值得参加"

【输出要求】
- 微信群模板可以直接复制使用
- 整理清单要具体到"打开手机相册，找到XX照片，重命名为XX"
- 总字数控制在2500字以内
```

---

## 使用说明

1. 活动前3天：用 **Prompt B**（准备清单）开始采购和准备
2. 活动前1天：用 **Prompt A**（逐字稿）过一遍流程，记住关键话术
3. 活动当天：带着 **Prompt C**（引导技巧手册）去现场
4. 活动当晚：用 **Prompt D**（收尾与家长沟通）做整理和反馈

每个 prompt 中的 `[X]` 和 `[填入]` 部分，使用时替换为实际内容。
