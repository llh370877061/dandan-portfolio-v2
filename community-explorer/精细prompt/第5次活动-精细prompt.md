# 第5次活动 · 精细 Prompt

> 活动名称：我们的改变计划
> 核心目标：围绕选定议题，头脑风暴，制定行动计划，合理分工
> 参与者：6-8个孩子（9-11岁）+ 4-5个家长
> 活动时长：2-2.5小时
> 绘本：可选《小黑鱼》讨论合作的力量
> ⚠️ 基于第4次投票选出的"最想改变的一件事"来设计

---

## Prompt A：逐字稿

```
你是一位温暖、有感染力的儿童社区探索活动领队，现在要为第5次活动写一份逐字稿。这次的主题是"我们的改变计划"，孩子们要围绕上次投票选出的问题，头脑风暴、制定行动计划、分工。这是从"想改变"到"真的去改变"的关键一步。

【参与者信息】
- 6-8个孩子（9-11岁），已经参加过4次活动，团队默契很好
- 4-5个家长陪同，已经完全信任你
- 上次投票选出的改变方向：[填入，如"社区里的垃圾问题""缺少儿童活动空间""树被砍了"等]

【活动流程及时间分配】
1. 0:00-0:20 回顾"行动议题" + 头脑风暴
2. 0:20-0:40 集体决策：选择具体行动方案
3. 0:40-1:30 细化行动计划 + 分工
4. 1:30-2:10 实地考察 + 材料准备清单

【逐字稿要求】

请为每个环节写出完整的引导语，格式如下：

---
【环节名称】 时间段

（你站在白板前，指着上次投票结果）

"……"（具体的开场白/引导语）

[转身写下关键词]

"……"（引导话术）

孩子可能说："……"（预判3种可能的回答）

你回应："……"（针对每种回答的具体回应）
---

具体要求：

1. **回顾与头脑风暴环节**：
   - 开场白：回顾上次投票结果（"上次我们一起选出了最想改变的问题——[问题]，今天我们要把它变成真正的行动！"）
   - 用头脑风暴法引导孩子说出各种想法
   - 规则：不评判、不否定、全部记录、想到什么说什么
   - 你怎么记录（在白板上快速写关键词）
   - 如果孩子说的方案太天马行空怎么办（先记下来，后面再筛选）
   - 如果孩子说"我没什么想法"怎么引导
   - 头脑风暴结束后怎么过渡到筛选

2. **集体决策环节**：
   - 从头脑风暴中选出最可行的1-2个方案
   - 引导思考的三个问题：
     - "我们能做到吗？"（可行性）
     - "需要什么材料和帮助？"（资源）
     - "可能遇到什么困难？"（风险）
   - 投票方法（举手/贴纸）
   - 投票前让孩子说"我想选XX，因为……"
   - 宣布结果的仪式感
   - 如何处理没被选中的方案（"这些想法很棒，我们以后还可以做"）

3. **细化行动计划环节**：
   - 确定方案后，一起制定行动计划
   - 四个关键要素：
     - 分工：谁负责什么？（让孩子主动认领）
     - 材料：需要准备什么？（列出清单）
     - 时间：什么时候动手？（第6次活动当天）
     - 安全：需要注意什么？
   - 行动计划写在大纸上（让孩子画+大人帮忙写）
   - 每个孩子至少认领一个任务
   - 如果有两个孩子想做同一个任务怎么办（可以一起做，或者轮流）
   - 如何让孩子对自己的任务有"责任感"

4. **实地考察+材料准备环节**：
   - 如果条件允许，去"要改变的地方"实地考察
   - 拍照记录"改变前"的样子（为展览的"前后对比"做准备）
   - 讨论需要家长帮忙准备的材料
   - 分配材料准备任务（哪些家长准备什么）
   - 预告："下次就是我们的'动手日'！"

【整体语言风格】
- 这次活动比较"理性"（讨论+计划），要保持孩子的参与热情
- 多用"我们""一起""团队"强调合作
- 让孩子感到"我的想法被重视""我的任务很重要"
- 关键话术加粗
- 标注语气提示：[郑重地] [兴奋地] [环顾所有人]

总字数控制在2500字以内。
```

## Prompt B：活动前准备清单

```
你是一位经验丰富的儿童活动策划师，现在要为第5次社区探索活动制定详细准备清单。

【活动信息】
- 活动名称：我们的改变计划
- 参与者：6-8个孩子 + 家长
- 核心材料：A2大白纸、彩色笔、马克笔、行动计划模板、第4次投票结果

【请按时间倒推列出准备清单】

一、活动前3天
- 回顾第4次投票结果（哪个问题被选中）
- 准备行动计划模板（可以手绘，包含：任务、负责人、材料、时间）
- 想好头脑风暴的引导问题
- 家长群通知文案（预告"今天要制定行动计划"）

二、活动前1天
- 材料打包清单
- 如果需要实地考察，确认路线
- 材料准备分配表（提前想好每家准备什么）
- 家长群提醒文案

三、活动当天
- 白板/大纸准备（用于头脑风暴记录）
- 分组/分工讨论的安排
- 相机/手机充电（记录过程）
- 安全检查清单

四、家长沟通
- 给家长的"材料准备任务单"（具体到每家准备什么）
- 告诉家长"这次活动的意义"（孩子在学习做决策、做计划）

【输出要求】
- 清单格式，可直接打印执行
- 材料准备任务单要具体到每个家庭
- 文案示例可直接复制
- 总字数控制在2000字以内
```

## Prompt C：现场引导技巧手册

```
你是一位有10年经验的儿童户外教育导师，现在要为第5次"我们的改变计划"活动准备现场引导手册。

【场景设定】
- 6-8个孩子（9-11岁）+ 家长，第5次参加活动
- 今天要头脑风暴、做决策、制定行动计划
- 活动流程：回顾→头脑风暴→决策→计划→考察

【请分场景回答，每个场景给2-3个具体方法，每个方法配一句示范话术】

一、头脑风暴环节
- 孩子的点子太天马行空怎么办（如"把整个社区拆了重来"）
- 孩子说"我没什么想法"怎么办
- 有孩子一直说不让别人说怎么办
- 孩子的点子重复怎么办（怎么引导从不同角度想）
- 有孩子说"这个问题解决不了"怎么回应
- 有孩子说"这和我没关系"怎么引导

二、决策环节
- 孩子们意见分歧很大怎么办
- 有孩子因为自己的方案没被选中而不高兴怎么办
- 有孩子说"我选XX是因为XX也选了"（跟风）怎么引导独立思考
- 投票结果很接近怎么办（如何处理平票）
- 有孩子说"我不想参加这个行动"怎么办

三、计划制定环节
- 孩子不知道怎么分工怎么办
- 有两个孩子想做同一个任务怎么办
- 有孩子选了超出能力范围的任务怎么办
- 孩子对"安全注意事项"不感兴趣怎么办
- 行动计划写得太简单怎么办

四、实地考察环节
- 到了现场孩子不认真看怎么办
- 有孩子说"这里和上次不一样了"怎么办
- 拍照时孩子不愿意配合怎么办
- 天气不好不能实地考察怎么办

五、全程通用
- 如何让孩子从"我想改变"到"我真的能做到"
- 如何让每个孩子都有"被需要"的感觉
- 如何让孩子对下次"动手日"充满期待

【输出要求】
- 不要理论，要"我现在就可以照着做"的操作指南
- 特别关注"意见分歧"和"选不到任务"这两个常见状况
- 总字数控制在2500字以内
```

## Prompt D：活动后收尾与家长沟通

```
你是一位儿童活动运营专家，现在要指导一位新手领队完成第5次活动后的收尾工作。

【背景】
- 第5次活动刚结束
- 孩子们头脑风暴、投票、制定了行动计划、分工明确
- 下次（第6次）就是"动手日"——真正去改变+办展览
- 这是最后一次"准备活动"，需要为第6次做好所有铺垫

【请完成以下四项任务】

一、5分钟收尾环节
- 总结今天的行动计划（让孩子有"我们准备好了"的感觉）
- 确认每个孩子的任务（"你是XX负责人，对不对？"）
- 预告："下次就是我们的大日子！我们要去改变，还要办展览！"
- 结束仪式

二、当天晚上整理
- 行动计划拍照存档
- 材料准备确认表（谁负责什么、进度如何）
- "改变前"照片整理（为展览的"前后对比"做准备）
- 为第6次活动准备什么（布展材料、证书、食物等）
- 展览布置方案确认（选哪个公园展览方案）

三、微信群反馈
请写出3条不同风格的反馈模板：

模板A（简洁版）：
- 核心：今天制定了计划+分工完成+下次是大日子

模板B（温馨版）：
- 核心：头脑风暴回顾+孩子们的创意+分工情况+对下次的期待

模板C（详细版）：
- 核心：活动回顾+讨论过程亮点+最终方案+每个孩子的任务+需要家长配合的材料+下次预告

重点传递：孩子们在学习做决策、做计划、分工合作，这是非常重要的能力。

四、家长沟通（为第6次活动做铺垫）
- 需要家长配合的具体事项（材料、时间、到场）
- 如何让家长为第6次活动请假/调整时间
- 如何让家长邀请朋友来参观展览
- 如何让家长理解"这次展览对孩子有多重要"
- 如果有家长说"下次来不了"怎么沟通

【输出要求】
- 微信群模板可直接复制使用
- 材料准备确认表要具体
- 总字数控制在2500字以内
```

## 使用说明

1. 活动前3天：用 **Prompt B**（准备清单）回顾投票结果、准备材料
2. 活动前1天：用 **Prompt A**（逐字稿）过一遍流程
3. 活动当天：带着 **Prompt C**（引导技巧手册）去现场
4. 活动当晚：用 **Prompt D**（收尾与家长沟通）做整理和反馈，为第6次做准备
