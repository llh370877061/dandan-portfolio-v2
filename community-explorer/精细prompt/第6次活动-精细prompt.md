# 第6次活动 · 精细 Prompt

> 活动名称：社区展览 & 庆祝
> 核心目标：展示成果，庆祝成长，颁发证书，为整个探索旅程画上圆满句号
> 参与者：6-8个孩子（9-11岁）+ 4-5个家长 + 可能的社区参观者
> 活动时长：2.5-3小时（比平时长一些）
> 绘本：《花婆婆》作为结尾线索——"做一件让世界变得更美好的事"
> ⚠️ 这是最后一次活动，要有仪式感、有温度、有成就感

---

## Prompt A：逐字稿

```
你是一位温暖、有感染力的儿童社区探索活动领队，现在要为第6次（也是最后一次）活动写一份逐字稿。这次是"社区展览 & 庆祝"，孩子们要布展、做导览员、回顾6次旅程、给社区写信、领证书。这是整个活动的高潮，要有仪式感、有温度、有成就感。

【参与者信息】
- 6-8个孩子（9-11岁），已经参加过5次活动，从陌生到熟悉到默契
- 4-5个家长陪同，已经完全信任你，非常支持
- 可能有社区居民来参观展览
- 孩子们有：社区地图、侦察报告、人物小传、行动计划书、"改变前"照片

【活动流程及时间分配】
1. 0:00-0:30 一起布置展览
2. 0:30-1:00 小小导览员讲解
3. 1:00-1:30 体验圈大回顾
4. 1:30-1:50 给社区写一封信
5. 1:50-2:10 庆祝仪式 + 颁发证书

【逐字稿要求】

请为每个环节写出完整的引导语，格式如下：

---
【环节名称】 时间段

（你站在展览场地，手里拿着准备好的材料）

"……"（具体的开场白/引导语）

[拿起一件展品]

"……"（具体的引导话术）

孩子可能说："……"（预判3种可能的回答）

你回应："……"（针对每种回答的具体回应）
---

具体要求：

1. **布展环节**：
   - 开场白（今天是大日子，要有兴奋感）
   - 布展的分工（每个孩子负责自己最得意的作品）
   - 展览区域规划（哪个区域放什么）
   - 挂作品/摆放的具体操作（用麻绳+木夹、或用展板）
   - 孩子在布展时怎么引导（"你觉得这个放哪里最好？"）
   - 布展完成后怎么验收（"我们的展览准备好了！"）
   - 如果有社区居民路过好奇地看，怎么引导孩子主动打招呼

2. **导览员环节**：
   - 邀请参观者的话术（如果有外部参观者）
   - 每个孩子做自己作品的导览员
   - 导览词示范（孩子可以照着说的版本）：
     - "大家好，我是XX，这是我画的社区地图。我画了……"
     - "这是我们采访的XX叔叔/阿姨的故事。他告诉我们……"
     - "这是我们发现的问题，我们决定……"
   - 孩子讲解时你在旁边做什么（不代替，只在需要时补充）
   - 如果孩子紧张说不出来怎么办
   - 如果参观者问孩子问题怎么引导回答
   - 没有外部参观者时，家庭之间互相导览

3. **体验圈大回顾环节**：
   - 围坐，用完整体验圈回顾6次旅程
   - 体验："这6次活动，你印象最深的是什么？"
   - 反思："你学到了什么？改变了什么想法？"
   - 归纳："用一个词/一句话形容你的社区"
   - 应用："以后你会怎么和社区相处？"
   - 每个层次怎么引导（给具体的追问话术）
   - 如果孩子说不出"深刻的"感受怎么引导（不要逼，让孩子说真实的）
   - 如何让回顾不变成"说教"（让孩子说，你只追问和肯定）
   - 温情时刻："你们从第1次到现在，真的长大了"

4. **给社区写信环节**：
   - 发学习单"给社区的一封信"
   - "你可以写文字，也可以画画，或者又写又画"
   - 示范："亲爱的社区，我最喜欢你的是……我希望你……"
   - 孩子写/画时你在旁边做什么（安静陪伴，不催促）
   - 如果孩子说"我不知道写什么"怎么引导
   - 写完后怎么处理（贴在展览上/带回家/收进档案）

5. **庆祝仪式环节**：
   - 颁发"社区探索家"证书（提前制作好）
   - 一个一个颁发，每个孩子都有个性化的话（不要只说"恭喜"）
   - 每个孩子颁发时说什么（给8个示范话术，针对不同性格的孩子）
   - 一起合影留念
   - 分享小点心
   - 结束语（温暖、有力量、展望未来）
   - 最后的结束口令/动作

【整体语言风格】
- 这是最后一次活动，要有"旅程感"——从第1次到第6次
- 温暖、真诚、有仪式感
- 多用"我们一起""你们做到了""了不起"
- 不要说教，让孩子自己感受到成长
- 关键话术加粗
- 标注语气提示：[眼眶微红] [拥抱] [竖起大拇指] [郑重地]

总字数控制在3000字以内（这次活动内容多，可以长一些）。
```

## Prompt B：活动前准备清单

```
你是一位经验丰富的儿童活动策划师，现在要为第6次（最后一次）社区探索活动制定详细准备清单。这是最重要的一次活动，需要最多的准备。

【活动信息】
- 活动名称：社区展览 & 庆祝
- 参与者：6-8个孩子 + 家长 + 可能的社区参观者
- 核心材料：所有前5次活动的作品、展览布置材料、证书、食物
- 展览地点：社区公园（选一个公园展览布置方案）

【请按时间倒推列出准备清单】

一、活动前7天
- 展览方案确认（选哪个公园展览布置方案）
- 展览场地确认（能否使用、需要什么许可）
- 需要家长配合的事项（材料、时间、邀请朋友参观）
- 家长群通知文案（预告展览+邀请参观者）

二、活动前3天
- 展览布置材料采购/准备清单：
  - 麻绳、木夹、展板、标签纸等
  - 证书打印/制作
  - 食物/点心准备
- 所有前5次活动的作品整理清单（哪些需要打印、哪些需要装裱）
- 家长群详细通知（时间、地点、需要带什么）
- 邀请参观者（邻居、社区居民、朋友）

三、活动前1天
- 所有材料打包清单（逐项打勾）
- 展览布置图（哪个区域放什么）
- 证书按孩子姓名排列
- 食物/点心准备
- 天气确认（户外展览的备选方案）
- 家长群最终提醒

四、活动当天
- 提前1小时到场布置
- 布置顺序：先挂作品→再放标识→再摆食物→最后检查
- 音响/音乐准备（如果有）
- 相机/手机充电
- 拍照分工（谁负责拍照/录像）

五、家长沟通
- 给家长的"最终通知"（时间、地点、需要做什么）
- 家长的任务（邀请参观者、帮忙布置、拍照）
- 感谢信（给所有参与过的家长一段感谢的话）

【输出要求】
- 清单格式，可直接打印执行
- 作品整理要具体到"第1次的学习单打印出来，第2次的侦察报告打印出来"等
- 展览布置图要具体
- 文案示例可直接复制
- 总字数控制在2500字以内
```

## Prompt C：现场引导技巧手册

```
你是一位有10年经验的儿童户外教育导师，现在要为第6次（最后一次）"社区展览 & 庆祝"活动准备现场引导手册。

【场景设定】
- 6-8个孩子（9-11岁）+ 家长，第6次也是最后一次活动
- 今天要布展、做导览员、回顾、写信、领证书
- 可能有外部参观者
- 孩子们既兴奋又可能有点不舍

【请分场景回答，每个场景给2-3个具体方法，每个方法配一句示范话术】

一、布展环节
- 孩子们抢着放自己的作品怎么办
- 有孩子说"我的作品不好看不想展出来"怎么办
- 布展时孩子不听指挥只想按自己想法来怎么办
- 布展进度慢时间不够怎么办
- 有社区居民路过好奇来看怎么引导孩子打招呼

二、导览员环节
- 孩子紧张不敢对着人讲解怎么办（最常见！）
- 孩子讲解时语无伦次怎么办
- 参观者问孩子答不上来的问题怎么办
- 有孩子一直讲不停怎么办
- 有孩子不想当导览员怎么办
- 没有外部参观者时怎么让家庭间互相导览也有仪式感

三、体验圈回顾环节
- 孩子说"我忘了之前做了什么"怎么办
- 有孩子说"我觉得没什么变化"怎么引导
- 有孩子情绪低落（因为要结束了）怎么办
- 回顾时孩子说的话很浅（如"好玩"）怎么引导深入
- 如何让回顾有温度而不是变成汇报

四、写信环节
- 孩子说"我不知道写什么"怎么办
- 孩子写得太短怎么办（要不要引导多写）
- 有孩子说"我不想写"怎么办
- 孩子的信写得不好怎么回应

五、颁证环节
- 颁证时怎么让每个孩子都有"高光时刻"
- 有孩子说"为什么他的是那款我的是这款"怎么办
- 颁证时孩子哭了怎么办
- 你说个性化评语时孩子是什么反应，怎么应对

六、全程通用
- 如何让今天的活动有"旅程终点"的感觉
- 如何让孩子不舍但不难过
- 如何让孩子觉得"这不是结束，是新的开始"
- 如何让家长感受到这6次活动的价值

【输出要求】
- 不要理论，要"我现在就可以照着做"的操作指南
- 特别关注"孩子紧张不敢讲解"和"颁证仪式"两个环节
- 给出8个颁证时的个性化话术（针对不同性格的孩子）
- 总字数控制在3000字以内
```

## Prompt D：活动后收尾与家长沟通

```
你是一位儿童活动运营专家，现在要指导一位新手领队完成第6次（最后一次）活动后的收尾工作。这是整个活动的终点，需要做好总结、感谢和未来规划。

【背景】
- 第6次活动刚结束
- 展览成功举办，孩子们当了导览员，领了证书
- 6次活动全部完成
- 需要做最终整理、感谢、和未来展望

【请完成以下四项任务】

一、活动当天收尾
- 展览撤展（哪些作品保留、哪些可以送给孩子、哪些归档）
- 场地清理
- 与家长的简短告别（不是永别，而是"这只是开始"）
- 最后的合影

二、最终整理（活动后1-3天）
- 所有6次活动的材料归档清单：
  - 学习单（按孩子分类）
  - 侦察报告
  - 人物小传
  - 社区地图
  - 行动计划书
  - 照片（按活动次数分类）
  - 展览照片
  - 证书存根
- 文件夹命名规则和存储方式
- 哪些材料有展览/收藏价值
- 为可能的后续活动（如"社区探索2.0"）保留什么

三、微信群最终反馈
请写出3条不同风格的反馈模板：

模板A（简洁版，50字以内）：
- 核心：6次活动圆满结束 + 感谢 + 展望

模板B（温馨版，150字以内）：
- 核心：6次旅程回顾 + 孩子们的成长 + 展览亮点 + 感谢家长 + 未来展望

模板C（详细版，300字以内）：
- 核心：6次活动完整回顾 + 每次活动的亮点 + 孩子们的具体成长（举例）+ 展览照片 + 感谢每位家长 + 未来展望 + 邀请继续参与

这是最后一条反馈，要有温度、有力量、有留恋。

四、未来规划
- 如何让这个活动继续下去（"社区探索2.0"的可能性）
- 如何保持家长群的活跃度（不是活动结束就散了）
- 如何把这次活动的经验用于未来的活动
- 如何让孩子在日常生活中继续"观察社区"
- 如何让这次活动成为孩子的"成长记忆"

【输出要求】
- 微信群模板可直接复制使用，要有情感温度
- 归档清单要具体到每个文件
- 总字数控制在2500字以内
```

## 使用说明

1. 活动前7天：用 **Prompt B**（准备清单）确认展览方案、通知家长
2. 活动前3天：用 **Prompt B** 采购布置材料、整理所有作品
3. 活动前1天：用 **Prompt A**（逐字稿）过一遍流程，记住颁证话术
4. 活动当天：带着 **Prompt C**（引导技巧手册）去现场
5. 活动后1-3天：用 **Prompt D**（收尾与家长沟通）做最终整理和感谢
