# 社区探索活动 — 收尾与反馈指南

> 第1次活动结束后，家长在观望。这24小时内的动作决定了他们会不会继续参加。

---

## 一、5分钟收尾环节（活动结束前）

### 选一种收尾方式

**方式A：发现之墙**

（你铺开A2大白纸，把今天所有发现都写在上面）

"看！这是我们今天**一起发现的**。"

[指着大白纸，一个一个念]

"这里有——**XX个人、XX个景、XX个地、XX个产、XX个文**。"

[停顿3秒]

"这些发现，**全部都是你们的眼睛看到的**。在今天之前，你们可能天天经过这些地方，但从来没有这样看过。"

[成就感时刻]
"**今天你们每一个人都是探索家。不是因为你们发现了什么了不起的东西——而是因为你们用全新的眼睛，看到了自己熟悉的地方。** 这就是探索的意义。"

**方式B：时间胶囊**

[拿出一个信封或小盒子]

"今天，我们要把你们的发现**封存起来**。"

[让每个孩子把自己的学习单折好，放进信封]

"这个信封，等到我们这个系列结束的那一天——我们一起打开，看看你们从第1次到第1次，**发现了多少变化**。"

[成就感时刻]
"**你们今天种下了一颗种子。等它长大，我们再一起看。**"

**方式C：击掌仪式**

"好！最后——来，**每个人跟我击一次掌**！"

[走到每个孩子面前，击掌]

"你的名字是？好！**XXX，今天你是探索家！**"

[逐个击掌，每个孩子都得到一次专属的肯定]

[成就感时刻]
"**你们8个人加在一起，今天发现了XX个地方。这就是团队的力量。**"

### 预告下次活动

"对了——**下次我们要做一件更酷的事情**。"

[停顿，环顾所有人，制造悬念]

"今天你们用眼睛看了社区。下次——**我们要用双手去改变社区**。"

[不要说太多，留白]

"具体怎么做？**下次来了你就知道了**。我保证——比今天还好玩。"

### 结束口令

"好！最后——来！"

"**我说'出发'，你们说'探索'！**"

"**出发——**"（孩子们）"**探索！**"

"**出发——**"（孩子们）"**探索！**"

"今天的探索家们——**解散！**"

[鼓掌，让家长和孩子自由拍照]

## 二、当天晚上整理（活动结束后2小时内）

### 必须当天做的事

**1. 照片分类**

- 打开手机相册，找到今天拍的所有照片
- 按以下分类存入电脑/云端：

| 文件夹 | 内容 |
|--------|------|
| `01_活动记录/` | 活动流程照片（破冰、共读、分享） |
| `02_孩子作品/` | 学习单、五维观察卡的完成照片 |
| `03_孩子专注/` | 孩子认真观察、画画、讨论的特写 |
| `04_集体/` | 合影、分组合影 |
| `05_花絮/` | 好笑的、有趣的瞬间 |

**2. 文件夹命名规则**

```
2026-05-31_社区探索D1_[地点]
```

示例：`2026-05-31_社区探索D1_龙华公园`

所有子文件夹都在这个主文件夹下。以后每次活动新建一个主文件夹。

**3. 标记"展览素材"**

从 `03_孩子专注/` 和 `02_孩子作品/` 中，挑出以下照片标记"展览素材"：

- 孩子蹲下来观察地面的特写
- 孩子指着某个东西跟同伴说"看！"的瞬间
- 学习单上画得特别认真的页面
- 五维观察卡上写得最多的那张
- 孩子专注画画的侧脸
- 分享环节孩子举手发言的照片

**4. 记录关键发现**

打开今天的大白纸（拍照存档），把上面的内容打一份电子版：

```
# 2026-05-31 第1次活动发现记录

## 人
- （记录今天孩子们发现的所有"人"）

## 文
- ...

## 地
- ...

## 产
- ...

## 景
- ...
```

**5. 为下次活动准备**

- 今天孩子们对哪个维度最感兴趣？（记下来，下次多设计那个维度的引导）
- 有没有孩子提出了特别的问题？（下次活动可以衔接）
- 路线有没有安全问题？（记下来，下次避开或改进）

## 四、家长信任建立策略

### 家长最可能有的3个顾虑

**顾虑1："这个活动安全吗？"**

- **化解方式**：在反馈中自然提到安全措施，不刻意强调但让孩子知道你在意。
- **示范话术**：活动照片中有一张是"过马路时大人站在最前面"——发照片时配文："**今天过马路的时候，大人们都走在最前面，孩子们在后面跟着，秩序特别好。**"

**顾虑2："孩子学到了什么？"**

- **化解方式**：不要说"学到了知识"，而是展示孩子的变化——"从不知道到知道"。
- **示范话术**：**"今天出发前我问他们'你对社区了解多少？'有人说'就那样吧'。回来后有个孩子说'原来我们社区有这么多我不知道的事情'——这就是探索的意义。"**

**顾虑3："下次还来吗？值得继续吗？"**

- **化解方式**：制造期待感，但不剧透。
- **示范话术**：**"下次我们要做一件更酷的事情——今天只是热身。我保证比今天还好玩。"**

### 如何让家长觉得"比我想象的好"

1. **照片说话**：发2-3张孩子专注观察的照片——比任何文字都有说服力。
2. **引用孩子的话**：原话比你的描述更有力量。"有个孩子说'原来我们社区有这么多我不知道的事情'"。
3. **展示过程而非结果**：不要发"完美合影"，要发"孩子蹲在地上认真看青苔"——这才是家长想看到的。

### 如何让家长主动告诉别的家长

1. **给家长一个"社交货币"**：让家长拍到孩子专注的照片——他们会自发发朋友圈。
2. **让家长有参与感**：下次活动让家长当"记录员"或"安全员"——他们会跟朋友说"我今天带孩子去做了社区探索"。
3. **制造稀缺感**："下次名额有限，想参加的提前说"——家长会主动拉人。
