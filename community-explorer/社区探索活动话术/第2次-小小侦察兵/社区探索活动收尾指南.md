# 小小侦察兵 — 收尾与反馈指南

> 第2次活动结束，家长开始从"观望"转向"认可"。这24小时是巩固信任的关键。

---

## 一、5分钟收尾环节

### 仪式感收尾

（你站在围坐的孩子们面前，表情认真）

"侦察兵们——**今天的任务，完成了。**"

[从袋子里拿出一份"侦察结业证书"或在每张学习单上盖一个"侦察完成"的章]

"每个完成今天任务的侦察兵——**你们正式晋升了**。"

[走到每个孩子面前，递过去]

"这是你的**侦察报告**——上面记录了你今天的发现。**带回去，放到你的侦察档案里**。"

[成就感时刻]
"**你们今天用三种方法侦察了社区，发现了XX个问题。这些问题不是坏事——发现问题的人，才是真正关心这个地方的人。**"

### 回顾（让孩子自己说）

"好——现在侦察兵们，**谁能告诉我，今天你学到了什么？**"

[不总结，只追问]

孩子可能说："望远镜观察法。"
你追问：**"对！那望远镜观察法要观察多久？要注意什么？"**

孩子可能说："画地图。"
你追问：**"画地图的时候，什么颜色代表最重要的？"**

孩子可能说："用表情标注地方。"
你追问：**"对！那你今天标了几个😊开心的地方？"**

### 预告下次

"好——侦察兵们，**下次我们要做一件更厉害的事**。"

[停顿，环顾所有人，压低声音]

"今天你们发现了问题。**下次——我们要去采访社区里的人**，问问他们：你觉得这里有什么问题？你想改变什么？"

[制造悬念]

"具体怎么采访？**你们回去先想一个问题——你最想问社区里的谁？** 下次告诉我。"

### 结束口令

"好！最后——**我说'侦察'，你们说'完毕'！**"

"**侦察——**"（孩子们）"**完毕！**"

"**侦察——**"（孩子们）"**完毕！**"

"今天的侦察兵们——**解散！**"

[鼓掌，家长和孩子自由拍照]

## 二、当天晚上整理

### 侦察报告整理

**按孩子分类存档：**

1. 打开手机相册/扫描件，找到今天所有侦察报告的照片
2. 按孩子命名文件夹：

```
第2次侦察报告/
├── 张三/
│   ├── 侦察报告_第1页.jpg
│   ├── 侦察报告_第2页.jpg
│   └── 地图作品.jpg
├── 李四/
│   └── ...
└── 全组合影.jpg
```

3. 文件命名规则：`日期_姓名_报告名称`
   示例：`2026-06-07_张三_侦察报告.jpg`

### 问题墙整理

1. **拍照存档**：问题墙A2纸正面、反面各拍一张，确保文字清晰
2. **打电子版**：按类型分类录入：

```
# 第2次活动问题墙

## 环境问题
- （记录具体问题）

## 设施问题
- ...

## 人际关系问题
- ...

## 安全问题
- ...
```

3. **标记来源**：每个问题标注是哪组发现的、谁提出的
4. **存入主文件夹**：`第2次-小小侦察兵/问题墙/`

### 照片整理

| 文件夹 | 内容 |
|--------|------|
| `01_侦察过程/` | 孩子观察、画地图、讨论的照片 |
| `02_作品/` | 侦察报告、地图作品、表情图的特写 |
| `03_汇报/` | 汇报环节、问题墙前的照片 |
| `04_集体/` | 合影、分组合影 |
| `05_花絮/` | 好笑的、有趣的瞬间 |

### 为展览积累的素材清单

从第2次开始，每次活动记录以下内容：

- [ ] 每个孩子的侦察报告（拍照+电子版）
- [ ] 每个孩子的地图作品（拍照）
- [ ] 问题墙照片+电子版
- [ ] 活动前后的对比（如果有）
- [ ] 孩子说的精彩语录（当天记下来，会忘）
- [ ] 家长的反馈（微信群截图）
- [ ] 活动数据：发现了多少问题、走了多少路、用了多少种方法

## 四、家长信任巩固

### 家长可能有的新顾虑

**顾虑1："孩子是不是只在玩？学到了什么？"**

- **化解方式**：在反馈中展示孩子的"方法论"——他们不只是看了，而是用了三种方法看。
- **示范话术**：**"今天孩子们学了三种侦察方法——望远镜观察法、宝藏地图法、表情图法。这不是随便走走，而是有方法的观察。"**

**顾虑2："问题墙上的问题真的能解决吗？"**

- **化解方式**：告诉家长这些问题会被跟进。
- **示范话术**：**"问题墙上的问题我们会带到下次活动——孩子们会去采访社区里的人，问问他们怎么看这些问题。这不是结束，是开始。"**

**顾虑3："下次还值得来吗？"**

- **化解方式**：制造期待感，让孩子回家主动说"我想去"。
- **示范话术**：**"下次我们要去采访社区里的人——这是孩子们第一次做'社区记者采访'，我相信他们会问出很有意思的问题。"**

### 如何让家长看到"孩子在学习"

1. **展示过程而非结果**：发孩子认真画地图、做观察的照片——比任何文字都有说服力。
2. **引用孩子的方法论**：**"孩子说'认真看3分钟和随便看一眼看到的东西不一样'——这就是他学到的。"**
3. **对比进步**：**"上次孩子只能观察1分钟就走神了，今天他安静观察了3分钟——这就是成长。"**

### 如何让家长主动推荐

1. **给家长"社交货币"**：孩子画的地图、做的侦察报告——家长会自发发朋友圈。
2. **制造稀缺感**：**"下次名额有限，想带朋友家孩子来的提前说。"**
3. **让孩子回家"教"家长**：**"回家可以让孩子教你望远镜观察法——观察家里的一棵树或一个角落，3分钟。"**

### 引导家长在家里延续

在反馈最后加一段：

> 💡 **回家小任务**
>
> 今天孩子学了"望远镜观察法"——回家可以试试：找一个地方（阳台的花、楼下的树、客厅的一个角落），安静看3分钟，看看你能发现什么。跟孩子比赛谁发现的多！
