# 画一张社区地图 — 收尾与反馈指南

> 第4次活动结束，这是转折点——从"观察"进入"行动"。今天的核心是"决策感"：孩子们自己决定了要改变什么。

---

## 一、5分钟收尾环节

### 总结投票结果

（你站在展示区前，表情郑重）

"好——侦察兵们，今天我们做了一件**很重要的事**。"

[停顿3秒]

"你们画了三张社区地图，然后——**你们投票选出了最想改变的一件事**。"

[指着投票结果]

"我宣布——**我们的决定是（念出投票最高的问题）！**"

[竖起大拇指]

"这不是我决定的——是**你们每一个人投票决定的**。这是集体的力量。"

[成就感时刻]
"**你们从观察者变成了决策者。你们不只发现了问题——你们还决定了要解决哪个问题。这就是成长。**"

### 预告下次

"好——那我们下次做什么？"

[压低声音，制造悬念]

"下次——**我们要为这个目标制定真正的行动计划**。"

"不是随便想想——是**真的要做**。我们要想：怎么做？需要什么？谁来做？什么时候做？"

[看着所有人]

"侦察兵发现问题→投票决定目标→**下次制定计划→然后——行动！**"

"你们准备好了吗？"

### 结束仪式

"好！最后——**我说'决定'，你们说'行动'！**"

"**决定——**"（孩子们）"**行动！**"

"**决定——**"（孩子们）"**行动！**"

"今天的小决策家们——**解散！**"

[鼓掌，家长和孩子自由拍照]

## 二、当天晚上整理

### 社区地图拍照存档

1. 把三张地图分别平铺在桌上/地上
2. 手机调成**俯拍模式**，确保整张地图入镜、文字清晰
3. 每张地图拍**全景+局部特写**（符号、标注、名字）
4. 命名规则：`第4次_社区地图_第X组.jpg`

### 投票结果记录

```
# 第4次活动投票记录

## 投票时间：2026-XX-XX

## 候选问题
1. （问题A）——X票
2. （问题B）——X票
3. （问题C）——X票
4. ...

## 最终决定
（得票最高的问题）

## 各组投票明细
- 第1组投了：...
- 第2组投了：...
- 第3组投了：...
```

### 照片整理

| 文件夹 | 内容 |
|--------|------|
| `01_创作过程/` | 孩子画地图、讨论、用贴纸的照片 |
| `02_作品/` | 三张地图的高清照片 |
| `03_展示/` | 孩子讲解地图的照片 |
| `04_投票/` | 孩子贴贴纸、计票、宣布结果的照片 |
| `05_集体/` | 合影 |

### 为展览积累的素材清单

从第4次开始，重点记录：

- [ ] 三张**社区地图原件**（展览核心作品）
- [ ] 投票结果**记录单**（展览的"决策过程"展示）
- [ ] 孩子**认真讨论、投票**的照片
- [ ] 孩子**讲解地图**的照片（展示环节）
- [ ] **对比素材**：第1次→第4次的变化（从"随便看看"到"画地图做决策"）

### 为第5次活动准备

- 回顾投票结果：选出的问题是什么？孩子们对这个问题的理解程度？
- 想想怎么引导孩子制定行动计划（分步骤、分工、时间表）
- 准备"行动计划"模板（学习单）

## 三、微信群反馈

> 今天画了社区地图，投票选出了"最想改变的一件事"——（问题）[可根据实际情况修改]。下次我们要制定行动计划！

### 模板B：温馨版（100字以内）

> 今天第四次活动——画一张社区地图。孩子们把前三次的发现全部画在了一张地图上，然后投票选出了最想改变的问题。[可根据实际情况修改] 有个孩子说"我们真的可以改变社区吗？"——当然可以！下次我们就来制定行动计划。

### 模板C：详细版（200字以内）

> 今天第四次社区探索活动——画一张社区地图，顺利完成！
>
> 孩子们把前三次活动的发现整合在一张地图上：侦察报告、人物小传、五维观察——全部画了进去。每组的地图风格都不一样，但都很认真。
>
> 然后是投票环节——孩子们用贴纸选出了"最想改变的一件事"。有个孩子投完票说"我们真的可以做决定" [可根据实际情况修改]。
>
> 从第1次的"发现者"，到第2次的"侦察兵"，到第3次的"小记者"，到今天的"决策者"——孩子们在一步步成长。他们不只学会了观察，还学会了做决定。
>
> 下次活动预告：我们要为这个目标制定**真正的行动计划**。侦察兵发现的问题，侦察兵自己来解决！

## 四、家长信任巩固

### 如何让家长为第5-6次做更积极的准备

1. **提前告知意义**——"接下来两次活动是'行动阶段'——孩子们会真的去改变社区。这需要家长的支持。"
2. **给具体任务**——"下次活动请家长帮忙准备：XXX（根据行动计划需要的材料）。"
3. **制造参与感**——"家长也可以参与行动计划——你们的经验对孩子很有帮助。"

### 如何让家长开始跟朋友说"要办展览了"

在反馈最后加一段：

> 🎨 **展览预告**
>
> 我们这个系列一共6次活动。**第6次我们会办一个小型展览**——把孩子们6次活动的所有发现、作品、故事展示出来。
>
> 今天画的社区地图、之前的人物小传、侦察报告——**都会出现在展览上**。
>
> 如果有朋友的孩子也想参加——**可以先联系我们，下次可以一起来**！

### 如何为第6次展览提前造势

1. **让家长保管作品**——"请帮孩子保管好每次活动的学习单和作品——这些都是展览的素材。"
2. **提前展示素材**——在群里发之前活动的精彩照片，让家长看到"素材已经很丰富了"。
3. **制造期待**——"展览不是我办的——是孩子们的作品展。你们到时候会看到孩子的成长。"
