# 社区探索活动 · 精细 Prompt 手册

> 每个 prompt 都可直接复制到任何 AI 对话中使用。
> 建议：每次活动前 3 天开始准备，按对应 prompt 逐步执行。

---

## Prompt 1：活动逐字稿

```
你是一位资深的儿童社区探索活动导师，现在要为第 [X] 次活动写一份可以照着念的逐字稿。

【活动信息】
- 活动名称：[填入，如"出发！走进我们的社区"]
- 参与者：6-8个孩子（9-11岁）+ 4-5个家长
- 活动时长：2-2.5小时
- 活动地点：社区公园/街道
- 核心目标：[填入，如"用五维观察法体验式认识社区"]

【活动流程】
- 0:00-0:20 破冰游戏
- 0:20-0:50 绘本共读/方法教学
- 0:50-1:10 引入框架/准备
- 1:10-1:50 户外探索
- 1:50-2:10 分享反思
- 2:10-2:20 收尾预告

【逐字稿要求】
1. 每个环节写出你说的具体语言，包括：
   - 开场白（怎么打招呼、怎么引起兴趣）
   - 环节之间的过渡语（怎么从上一个环节自然转到下一个）
   - 提问（用什么具体问题引导孩子思考）
   - 孩子可能的回答 + 你的回应（至少准备3种可能）
   - 突发情况应对（孩子说"好无聊"、孩子走散、孩子不想参与）
2. 语言风格：像跟朋友聊天一样自然，不要书面语，不要说教
3. 标注语气提示：[兴奋地] [蹲下来] [指着某处] [停顿3秒]
4. 在关键节点标注"成就感时刻"——让孩子觉得自己很棒的具体话术
5. 结尾要有仪式感，让孩子期待下一次

【输出格式】
按时间线排列，每个环节用分隔线隔开，关键话术加粗。
总字数控制在2000字以内，重点突出，不要废话。
```

## Prompt 2：活动前准备清单

```
你是一位经验丰富的儿童活动策划师，现在要为第 [X] 次社区探索活动制定详细的准备清单。

【活动信息】
- 活动名称：[填入]
- 活动时间：[填入，如"下周六上午9:30"]
- 活动地点：[填入]
- 参与者：6-8个孩子（9-11岁）+ 4-5个家长
- 核心材料：[列出需要的材料，如学习单、侦察兵证、五维观察卡等]

【准备清单要求】
1. 按时间倒推，列出从活动前3天到活动当天的每一项准备工作：
   - 活动前3天：需要购买/制作什么
   - 活动前1天：需要确认什么（天气、场地、人员）
   - 活动当天：提前多久到、怎么布置、怎么摆放材料
2. 每项工作标注：
   - ⏱️ 需要多长时间
   - 📦 具体要什么材料/工具
   - ⚠️ 容易忘记的点
3. 制造期待感的技巧：
   - 活动前3天在家长群发什么（示例文案）
   - 活动前1天发什么提醒
   - 活动当天早上发什么
4. 家长沟通要点：
   - 怎么说让家长理解这次活动的价值
   - 怎么说让家长愿意鼓励孩子参与
   - 家长在现场应该扮演什么角色（具体行为指南）

【输出格式】
用表格或清单形式，按时间顺序排列，可以直接打印出来执行。
```

## Prompt 3：活动中的引导技巧

```
你是一位有10年经验的儿童户外教育导师，现在要指导一位新手领队如何在社区探索活动中引导孩子。

【场景设定】
- 活动类型：户外社区探索，6-8个孩子（9-11岁）+ 家长
- 教学方法：体验圈（体验→反思→归纳→应用）
- 常见挑战：孩子走神、冷场、个别孩子主导、孩子不想参与

【请分模块回答以下问题，每个问题给出2-3个具体可操作的方法】

一、节奏把控
- 户外探索环节，孩子走太快或走太慢怎么办？
- 分享环节没人说话怎么办？
- 孩子在一个地方停留太久怎么办？
- 时间快到了但还没完成怎么办？

二、提问技巧
- 给出5个万能提问句式（可以直接用的原话）
- 孩子回答"不知道"时怎么追问
- 孩子给出简单答案（如"好看"）时怎么引导深入
- 如何用提问让孩子之间产生对话（而不是都对着领队说）

三、常见状况处理
- 有孩子说"好无聊"怎么办
- 有孩子一直拉着大人说话不参与集体活动怎么办
- 有两个孩子吵架/闹矛盾怎么办
- 孩子观察的内容完全偏离主题怎么办

四、成就感制造
- 活动中如何让每个孩子都觉得"我做到了"
- 如何让安静的孩子也有高光时刻
- 如何在分享环节点评孩子的发现（具体话术）

【输出要求】
- 每个方法都要给出可以直接用的示范语言
- 不要理论，要"我可以马上照着做"的操作指南
- 总字数控制在2500字以内
```

## Prompt 4：活动后收尾与家长沟通

```
你是一位儿童活动运营专家，现在要指导一位新手领队如何做好活动后的收尾工作和家长沟通。

【背景】
- 活动系列：6次社区探索活动，每周一次
- 参与者：6-8个孩子（9-11岁）+ 4-5个家长
- 当前进度：第 [X] 次活动结束
- 已有材料：孩子们的学习单、照片、访谈记录、社区地图、侦察报告等

【请回答以下四个问题】

一、5分钟收尾环节设计
- 每次活动结束后，用5分钟做什么样的收尾最有仪式感
- 给出3种收尾方式（可以轮换使用），每种都要有具体话术
- 如何让孩子觉得"今天没有白来"
- 如何自然地引出"下次期待"

二、作品和材料整理
- 每次活动后，哪些东西必须当天整理（照片、学习单、录音等）
- 用什么方式归档（文件夹命名规则、照片分类方法）
- 哪些材料要保留原件、哪些可以拍照后还给孩子
- 为最后展览做素材积累：从第1次开始就要记录什么

三、微信群反馈（每次活动后发给家长）
- 写3条不同风格的活动反馈模板（简洁版/温馨版/详细版）
- 每条模板包含：今日亮点、孩子表现、下次预告
- 如何让家长看到孩子的成长（而不是只说"今天很好玩"）
- 如何用反馈激发家长对下次活动的期待

四、长期信任建立
- 6次活动中，如何让家长从"试试看"变成"全力支持"
- 如何让家长主动在朋友圈分享活动
- 如何处理家长的担忧（安全问题、时间冲突、效果质疑）
- 如何让家长觉得"把孩子交给你我放心"

【输出要求】
- 微信群反馈模板可以直接复制使用
- 每个建议都要具体可执行，不要空话
- 总字数控制在3000字以内
```

## Prompt 5：展览策划与素材积累

```
你是一位社区展览策划专家，现在要为一个儿童社区探索活动设计最终展览方案。

【背景】
- 活动系列：6次社区探索活动
- 参与者：6-8个孩子（9-11岁）
- 展览地点：社区公园（有树林、草坪，有露营设备）
- 展览时间：第6次活动当天
- 已有资源：10种公园展览布置方案（实景版）、10种社区地图模板、10种人物小传模板、探索家证书

【请回答以下问题】

一、展览整体设计
- 展览应该分几个区域？每个区域放什么内容？
- 给出一个具体的参观动线（从入口到出口）
- 如何让展览既有"看的"又有"互动的"

二、素材加工清单
- 6次活动中产生的哪些素材可以用于展览？
- 每种素材如何加工（打印/装裱/放大/配文）？
- 列出一个"展览素材清单"，标注每项素材的来源和加工方式

三、孩子参与布展
- 如何让孩子参与布展过程（而不是大人全包）
- 哪些环节可以让孩子自己决定
- 如何让每个孩子都觉得"这个展览有我的贡献"

四、导览员培训
- 如何让孩子当"小小导览员"
- 给出一段示范导览词（孩子可以照着说）
- 如何让每个孩子都有机会讲解自己的作品

五、时间规划
- 从第1次活动开始，每次需要为展览做什么准备
- 列出一个6次活动的"展览素材积累时间表"
- 第5次活动后需要集中准备什么

【输出要求】
- 展览方案要可执行，适合6-8个孩子的规模
- 时间表要具体到每次活动需要做什么
- 总字数控制在3000字以内
```

---

## 使用说明

1. **每次活动前3天**：用 Prompt 1（逐字稿）+ Prompt 2（准备清单）
2. **每次活动当天**：带着逐字稿去，现场参考 Prompt 3（引导技巧）
3. **每次活动当天晚上**：用 Prompt 4（收尾与家长沟通）
4. **第1次活动后**：用 Prompt 5（展览策划）开始规划素材积累
5. 每个 prompt 中的 `[X]` 和 `[填入]` 部分，使用时替换为实际内容
