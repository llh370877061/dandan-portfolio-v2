## 二、暗壳科技 ｜ 多个岗位

### 公司背景
- 天使轮，政府基金近千万融资
- 全球住宅设计上市公司投资孵化
- 腾讯设计 AIGC 联合实验室联合发起方
- 产品：Lovspark（海外品牌名）— AI 空间设计工作台
- 目标用户：室内设计师、建筑师、空间设计工作室、家居品牌、视觉创作者

---

### JD-01：高级算法应用工程师（AIGC 与 3D 重建方向）

**一句话定位**：把 AI 生成能力工程化落地——让"文字描述一个房间"变成"输出可用的 3D 模型"。

**核心职责**：
1. 从文本/图像生成 3D 资产（Mesh/Texture）的算法研发与优化
2. 3D 与物理引擎集成，让生成模型可交互
3. Python + Docker 容器化，搭建高可用生成式 AI 系统
4. 跟踪 NeRF、Gaussian Splatting、3D Diffusion 前沿技术

**必备技能**：
- Python 精通 + 深度学习框架（PyTorch）
- ControlNet / LoRA / CLIP（AIGC 核心技术栈）
- 3D 重建（NeRF / 3D Gaussian Splatting / SLAM）
- Docker 容器化 + CI/CD
- 跨团队协作（需和 Unity/Unreal 引擎团队配合）

**人才画像**：硕士起步（博士优先），3年+ AIGC 或 3D 视觉开发经验。能把论文变成服务的工程师。

---

### JD-02：高级算法工程师（Physical AI & World Model 方向）

**一句话定位**：让 AI 不只"看到"空间，还能"理解"空间的物理规律。

**核心职责**：
1. 构建融合视觉生成与物理仿真的 World Model
2. 把建材物理参数（力学/热学/声学/光学）注入生成模型
3. 搭建具身智能仿真环境，训练 Agent 做空间交互
4. 时空图神经网络 / Agent-Based Modeling 跨尺度推演

**专业术语**：
- World Model：能模拟因果关系的系统，不只是生成图像
- Physical AI：让 AI 具备物理常识，生成结果物理上说得通
- PINNs：把物理方程嵌入神经网络训练，输出天然符合物理规律
- Embodied Agent：有"身体"的 AI 智能体，能在环境中行动和交互

**必备技能**：
- PyTorch / JAX + 物理仿真引擎（MuJoCo / PyBullet / Taichi / NVIDIA Omniverse）
- 3D Vision（NeRF / 3DGS / SLAM）
- 强化学习 / 模仿学习基础
- 物理属性与视觉生成的联合优化

**人才画像**：博士优先，纯研究型但需能工程化落地。同时理解计算机视觉和物理世界的稀缺复合背景。

**必备技能**：

**人才画像**：5年+经验，懂产品、懂数据、懂设计行业的增长操盘手。

**一句话定位**：把 Lovspark 产品能力翻译成海外设计师愿意看、愿意传的内容。

## 各岗位在公司中的协作关系

```
产品技术层（JD-01 + JD-02）
  ├── JD-01：让 AI 能生成 3D 空间方案（核心能力构建）
  └── JD-02：让生成结果物理正确、可模拟（差异化壁垒）

增长传播层（JD-03 + JD-04）
  ├── JD-04：生产高质量内容，建立品牌认知（种草）

```

**底层逻辑**：技术团队负责"能做什么"，增长团队负责"让对的人知道并用起来"。四个岗位缺一不可。

## 三、微软小冰 ｜ 销售总监（广州）

### 公司背景
- 由微软（亚洲）互联网工程院人工智能小冰团队分拆而成
- 受微软前全球执行副总裁陆奇和沈向洋影响和支持
- 2020年成立，继承微软 AI 深厚积累
- 全球业务覆盖中国、日本、印度尼西亚等
- 产品线：AI + 数字人

### 岗位职责
1. 搭建直销团队，负责 AI & 数字人产品的售卖
2. 招聘新人、销售培养、客户陪访、业绩跟进、拓客创新
3. 为团队提供产品、销售、管理及文化培训
4. 理解传达公司政策，收集客户反馈同步业务
5. 从数据中发现问题，持续优化策略和计划
6. 带领团队完成业务目标和业绩达成

### 专业术语拆解
- **数字人**：AI 驱动的虚拟形象，可用于直播、客服、短视频等场景
- **直销**：不通过代理商，直接面对客户销售
- **SaaS**：Software as a Service，软件即服务，云端订阅模式
- **微盟/有赞**：国内主流 SaaS 渠道服务商，有大量中小企业客户资源

### 必备技能图谱

```
硬技能（必须有）
├── 3年+ 软件销售管理经验
├── 2年+ 直销管理经验
├── 微盟/有赞/飞书等渠道资源与经验优先
├── 数字人/短视频/直播/SaaS/互联网从业经验优先
└── 数据驱动的策略优化能力

软技能
├── 出色的人际沟通能力
├── 极强的目标导向
├── 超强执行力、抗压能力、自我管理能力
└── 赚钱欲望 + 明确结果导向

加分项
├── 有数字人/短视频/直播业务经验
├── 有 SaaS 行业销售资源
└── 有渠道合作经验（微盟、有赞、飞书等）
```

### 人才画像

这是一个**纯商务型管理岗位**，不需要技术背景，但需要深刻理解 AI 数字人产品的商业价值。核心是"能卖、能带团队卖"的人。

### 岗位价值分析

| 维度 | 分析 |
|------|------|
| 为什么现在招 | 小冰从微软分拆后需要独立建立商业化能力，销售总监是搭建直销体系的关键角色 |
| 这个岗位解决什么问题 | 把小冰的 AI/数字人技术从"技术展示"变成"商业收入" |
| 为什么要求微盟/有赞/飞书经验 | 这些渠道有大量中小企业客户，是数字人产品最可能的买单方 |
| 广州的选址逻辑 | 广州是华南商业中心，靠近大量制造业和贸易企业，数字人需求旺盛 |
| "赚钱欲望"的含义 | 天使轮后的小冰需要快速证明商业模型，销售团队负责人必须是"能出活"的人 |
