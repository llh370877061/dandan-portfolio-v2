猫眼看世界

以猫的第一视角，踏入炫彩的冒险地图

Pawsworth Adventures

核心概念

你是一只猫。你的世界从地面 23 厘米的高度展开——一切都比人类看到的更大、更近、更有质感。 你低头能看到自己的爪子，转身能看见自己的影子随光线变化。 每一张地图都是一个独立的世界，有自己的规则、色彩和故事。

🐾

第一人称猫视角

画面底部常驻两只猫爪，走路时交替抬起。影子随光源实时变化——正午缩短，黄昏拉长。跳跃时爪子离开画面，落地时微微震颤。

🌈

炫彩地图世界

火山的赤红岩浆、桃花源的粉白花雨、湖泊的碧蓝倒影——每张地图都有独特的色彩语言和视觉氛围，写实风格中融入梦幻光效。

🐱

偶遇其他猫咪

每张地图都有独特的猫居民。它们有自己的性格、行为和故事线。你可以和它们对话、合作完成任务，也可能遇到需要化解的小冲突。

🎯

地图专属任务

火山地图要你帮忙灭火、桃花源要你寻找散落的花瓣、湖泊要你追踪水下的神秘光影。每个任务都和地图的环境特性深度绑定。

第一人称视觉系统

画面构成示意

画面元素

  • 猫爪占据画面底部约 15%，走路时交替抬起
  • 影子跟随光源方向实时投射在地面上
  • 视角高度固定在猫眼位置（约 23cm），所有物体都显得高大
  • 头部微动时画面轻微晃动，模拟猫的步态
  • 受到惊吓时画面快速左右晃动（猫的警觉反应）
  • 瞳孔随环境光线变化：亮处缩成细线，暗处放大变圆

地图设计

🌋
熔岩之心
Volcano Heartland · 炽热与勇气的试炼

视觉风格

主色调：赤红、橙金、深灰。地面是凝固的黑色熔岩，缝隙中涌动着发光的岩浆河流。 天空被火山灰染成暗橘色，偶尔有流星般的火山弹划过。 地面的热度让空气产生轻微的扭曲折射效果。

  • 岩浆流动时有动态光影，映在猫爪上呈暖红色
  • 火山灰像金色雪花一样飘落
  • 踩在不同材质上爪垫颜色微微变化（热石偏红，冷石偏灰）

任务

  • 扑灭火山裂缝火：用尾巴扇灭蔓延的火苗，保护火山兔的家
  • 寻找降温水晶：散落在火山各处的蓝色水晶能降低岩浆温度
  • 火山猫的传承：帮助年迈的火山猫找到它年轻时埋藏的宝物
  • 岩浆桥搭建：推动冷却的岩石块，为被困的小动物搭桥
🌸
桃花源
Peach Blossom Spring · 宁静与秘密的花园

视觉风格

主色调：粉白、嫩绿、淡金。漫天飘落的桃花瓣铺满小径，阳光透过花枝洒下斑驳光影。 远处有薄雾笼罩的山丘，近处是潺潺溪流和长满青苔的石桥。 整体氛围宁静治愈，像走进了一幅水墨画。

  • 花瓣落在猫爪上会停留片刻再飘走
  • 水面有真实的倒影和波纹，能看到猫脸的反射
  • 黄昏时整片桃花林被染成金色，猫的影子拉得很长

任务

  • 收集七色花瓣：七种不同颜色的花瓣散落各处，拼成一幅画
  • 修复古桥：石桥断了，需要找到合适的石块重新搭建
  • 桃花猫的诗会：帮助害羞的桃花猫在月下诗会上朗读它的诗
  • 追踪蝴蝶群：跟随一群发光蝴蝶找到隐藏的桃花源入口
🌊
碧波幻境
Azure Mirage Lake · 水底的另一个世界

视觉风格

主色调：碧蓝、翠绿、银白。湖面平静如镜，倒映着天空和远山。 湖底有发光的水草和游动的鱼群，透过水面能看到斑斓的色彩。 夜间湖面会升起萤火虫般的光点，水面下有神秘的蓝色光芒闪烁。

  • 猫靠近水边时，能看到自己清晰的倒影
  • 爪子触水时产生涟漪，倒影随之波动
  • 不同深度的水呈现不同蓝色层次，从浅蓝到深靛

任务

  • 打捞落水星光：星星掉进了湖里，需要找到方法捞上来
  • 湖底迷宫：潜入浅水区，穿过水草迷宫找到出口
  • 鱼群音乐会：帮助湖猫组织一场水下音乐会
  • 月光钓手：在特定月相下钓鱼，钓到传说中的月光鱼

猫咪图鉴

每张地图都有独特的猫居民。它们不是 NPC——它们有自己的脾气、习惯和故事。

🐱

炎爪

火山猫 · 橘色虎斑
性格火爆但心地善良，守护火山免受灾害。走路时爪子会微微发光，是火山赋予的特殊能力。
🐱

花辞

桃花猫 · 白色长毛
安静害羞，喜欢在桃花树下写诗。毛发上永远沾着几片花瓣，走动时会飘落。
🐱

涟漪

湖猫 · 蓝色暹罗
优雅神秘，能听懂水的语言。眼睛在黑暗中会发出幽蓝色的光，擅长潜水和游泳。
🐱

铜铃

流浪猫 · 三花
活泼好动，穿梭于各张地图之间。脖子上挂着一个小铜铃，走到哪里都叮当响。
🐱

墨影

暗影猫 · 纯黑
独来独往，行踪神秘。只在夜晚出现，毛发在月光下会泛出紫色光泽。
🐱

苔藓

森林猫 · 绿眼缅因
温和稳重，是所有猫的长辈。身上覆盖着薄薄的苔藓纹路，与自然融为一体。

炫彩视觉特效

💫

光线追踪

实时计算猫影子的方向和长度。正午影子缩成脚下一个小圆，黄昏影子拉长到十几米外。猫走过不同光源时，影子方向平滑过渡。

🌈

粒子特效

火山地图的飘落火山灰、桃花源的花瓣雨、湖泊的萤火光点。每片粒子都有独立的物理轨迹，随风摆动、受猫的移动影响。

💧

水面反射

湖面实时反射周围环境和猫的倒影。爪子触水时涟漪向四周扩散，倒影随之扭曲变形。水下物体有折射偏移效果。

🌙

昼夜循环

每张地图有独立的时间流逝。白天和夜晚的光影完全不同——夜晚的火山更红，桃花源更静谧，湖泊有月光银辉。

任务流程

探索
自由探索地图，发现环境中的线索和可互动物体
偶遇
遇到其他猫，通过行为和对话了解它们的困境
接受
选择是否帮助——不同选择导向不同任务分支
执行
利用猫的能力（跳跃、潜行、攀爬）完成任务
影响
任务结果改变地图面貌，解锁新区域和新故事线
