# 方案A：3天精华版详细时间表

> 纯市区，不跑远，适合时间紧的家庭
> 节奏：轻松，每天最多3个景点

---

## Day 1｜抵达 + 初识山城

| 时间 | 安排 | 细节 |
|---|---|---|
| 上午/中午 | 抵达重庆 | 飞机/高铁到市区，打车到酒店 |
| 14:00 | 入住酒店 | 推荐住解放碑附近，放行李休息 |
| 15:00 | 解放碑步行街 | 地标打卡，路面平坦，孩子可以跑跳 |
| 16:00 | 八一好吃街 | 豌杂面、酸辣粉、熊猫汤圆、一只酸奶牛 |
| 17:30 | 回酒店小憩 | |
| 18:30 | 长江索道 | 南岸→北岸，俯瞰长江 |
| 19:30 | 洪崖洞夜景 | 11楼进1楼出，不爬楼梯 |
| 20:30 | 晚餐 | 珮姐火锅（鸳鸯锅）或丘二馆鸡汤 |
| 21:30 | 回酒店 | |

**今日花费**：约300-500元（4人，不含住宿交通）
