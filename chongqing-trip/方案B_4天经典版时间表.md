# 方案B：4天经典版详细时间表

> 市区2天 + 武隆1天 + 收尾1天
> 节奏：中等，适合大部分家庭

---

## Day 1｜抵达 + 初识山城

| 时间 | 安排 | 细节 |
|---|---|---|
| 上午/中午 | 抵达重庆 | 飞机到江北机场，打车/地铁到酒店（约50分钟）；高铁到重庆北站，地铁直达（约30分钟） |
| 14:00 | 入住酒店 | 放行李、休息30分钟，让孩子缓一缓 |
| 15:00 | 解放碑步行街 | 地标打卡，路面平坦，推车也行，随手拍照 |
| 16:00 | 八一好吃街 | 边逛边吃：豌杂面（少辣）、酸辣粉、熊猫汤圆、一只酸奶牛 |
| 17:30 | 回酒店休息 | 孩子午睡或玩一会儿，为晚上攒体力 |
| 18:30 | 出发去长江索道 | 建议从南岸"上新街站"坐到北岸"小什字站"，俯瞰长江，孩子会很兴奋 |
| 19:30 | 洪崖洞夜景 | 亮灯了！从11楼进（顶层），平路走出去到1楼，不用爬楼梯。人多，牵好孩子 |
| 20:30 | 晚餐 | 洪崖洞附近吃：珮姐老火锅（鸳鸯锅）或丘二馆炖鸡汤（不辣） |
| 21:30 | 回酒店 | 第一天别太累，早点休息 |

**今日步行**：约8000步 | **今日花费**：约300-500元（交通+餐饮+索道）

---

## Day 2｜城市探索日

| 时间 | 安排 | 细节 |
|---|---|---|
| 8:00 | 酒店早餐 | 不赶时间，慢慢吃 |
| 9:00 | 李子坝轻轨穿楼 | 地铁2号线李子坝站下车，站楼下观景台看轻轨穿楼而过，拍创意照片。告诉孩子：这是中国唯一一座轻轨穿楼而过的站 |
| 10:00 | 鹅岭二厂文创园 | 从李子坝打车10分钟。《从你的全世界路过》取景地，拍照打卡，喝杯咖啡休息一下 |
| 11:30 | 午餐 | 鹅岭附近找家面馆或小餐馆 |
| 13:00 | 磁器口古镇 | 地铁1号线直达。老街逛逛，看手工艺制作，吃陈麻花（买伴手礼）。节奏慢，别赶，2-3小时足够 |
| 15:30 | 山城步道（第三步道） | 从磁器口打车到步道入口。这条步道相对平缓，能看江景，孩子走起来不累。沿途有老重庆的防空洞、吊脚楼 |
| 17:00 | 回酒店休息 | 换衣服，准备晚上 |
| 18:30 | 南滨路散步 | 对岸看洪崖洞更美，长嘉汇购物公园有儿童区 |
| 19:30 | 晚餐 | 南滨路吃：周师兄火锅 或 附近中餐馆 |
| 21:00 | 回酒店 | 明天要去武隆，早睡 |

**今日步行**：约12000步 | **今日花费**：约400-600元（餐饮+交通+零食）

---

## Day 3｜武隆天生三桥 + 仙女山

> 这天是全程最累也最精彩的一天

| 时间 | 安排 | 细节 |
|---|---|---|
| 6:30 | 出发 | 包车/跟团，市区到武隆约3小时。车上让孩子补觉 |
| 9:30 | 抵达天生三桥 | 世界自然遗产，喀斯特地貌。坐观光电梯下谷（不用爬！），沿步道走约2小时，全程平缓 |
| | | 看点：天龙桥、青龙桥、黑龙桥三座天然石桥，《变形金刚4》取景地 |
| | | 提前给孩子讲：这是地球用了几亿年"雕刻"出来的 |
| 11:30 | 午餐 | 仙女山镇上吃农家菜，武隆碗碗羊肉（不辣），新鲜蔬菜 |
| 13:00 | 仙女山国家森林公园 | 高山草原，1900米海拔，比市区凉5-8°C |
| | | 坐小火车穿行林海（25元/人，孩子超爱） |
| | | 草原上自由奔跑、拍照，预留1.5小时 |
| 15:00 | 返程 | 回市区约3小时。车上让孩子睡一觉 |
| 18:00 | 到酒店 | 晚餐就近解决：小面、酸辣粉等简单吃 |
| 20:00 | 休息 | 明天最后一天，放松 |

**今日步行**：约15000步（最累的一天）| **今日花费**：约800-1200元（包车+门票+餐饮）

**武隆注意事项**：
- 步道有台阶，穿防滑鞋
- 山上紫外线强，涂防晒
- 带一件薄外套，山上比市区凉
- 天生三桥游览约2小时，不要催孩子，让他们慢慢看
- 小火车排队可能30-45分钟，耐心等
